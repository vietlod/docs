## 15.2.3.1. Ý nghĩa phương pháp và phạm vi áp dụng

### 15.2.3.1.1. Bản chất kinh tế lượng

Approximates linear stationary dependent disturbances by finite-order AR(p) sieves, resamples centered i.i.d. innovations, and reconstructs pseudo-time-series to deliver valid dependent-data inference.

### 15.2.3.1.2. Phạm vi áp dụng và yêu cầu cấu trúc dữ liệu

Time-series and serially correlated regressions where i.i.d. bootstrap fails and smooth AR sieve resampling outperforms sharp-edge block boundaries.

- **Kiểm định tiền ước lượng bắt buộc**: `breusch_godfrey_serial_correlation, adf_unit_root`
- **Kiểm định hậu ước lượng bắt buộc**: `buhlmann_ar_sieve_bootstrap, durbin_watson_autocorrelation`

### 15.2.3.1.3. Hệ phương trình toán học và điều kiện định danh

Phương trình đặc tả cấu trúc của mô hình `sieve_bootstrap_buhlmann`:

$$
Y_i = m(X_i) + \varepsilon_i, \quad \min_{\alpha, \beta} \sum_{i=1}^N \left(Y_i - \alpha - (X_i - x)^\top \beta\right)^2 K_H(X_i - x)
$$

Hàm mục tiêu tối ưu hóa và điều kiện mô-men thực nghiệm:

$$
p_{\text{boot}} = \frac{1}{B}\sum_{b=1}^B \mathbb{I}\left(|t^{\ast(b)}| \ge |t_{\text{obs}}|\right), \quad y_g^{\ast(b)} = X_g \tilde{\beta} + v_g^{(b)}\tilde{u}_g
$$

Ma trận hiệp phương sai tiệm cận và đại lượng suy luận vững:

$$
h_{\text{opt}} = \arg\min_{h > 0} \frac{1}{N}\sum_{i=1}^N \left(Y_i - \hat{m}_{-i, h}(X_i)\right)^2
$$

# ==============================================================================
# BÀI 15.2.3 — MÃ BÀI B250: TÁI LẤY MẪU SÀNG TỰ HỒI QUY CHO CHUỖI PHỤ THUỘC THỜI GIAN BUHLMANN

# Tệp dữ liệu: vietlod_sieve_bootstrap_buhlmann_ecodata.csv | Cỡ mẫu N = 160
# ==============================================================================
import pandas as pd

df = pd.read_csv("vietlod_sieve_bootstrap_buhlmann_ecodata.csv")

# ECODATA replication & postestimation script - Autoregressive Sieve Bootstrap for Dependent Series Buhlmann (statsmodels::AutoregressiveSieveBootstrap)
# Family: nonparametric_resampling / resampling_permutation | Key: sieve_bootstrap_buhlmann
import pandas as pd
# df: a pandas DataFrame holding your selected variables
import numpy as np, statsmodels.api as sm
X = sm.add_constant(df[['x1', 'x2']]).values; y = df["y"].values
b = np.linalg.lstsq(X, y, rcond=None)[0]; u = y - X @ b
phi = float((u[1:] @ u[:-1]) / max(u[:-1] @ u[:-1], 1e-12))
e = (u[1:] - phi * u[:-1]); e -= e.mean(); rng = np.random.default_rng(42)
bs = []
for _ in range(299):
    es = rng.choice(e, size=len(y), replace=True); us = np.zeros(len(y))
    for t in range(1, len(y)): us[t] = phi * us[t-1] + es[t]
    bs.append(np.linalg.lstsq(X, X @ b + us, rcond=None)[0])
print("Sieve bootstrap SE:", np.std(bs, axis=0, ddof=1))
