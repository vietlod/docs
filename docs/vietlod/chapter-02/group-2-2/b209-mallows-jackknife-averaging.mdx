## 2.2.6.1. Ý nghĩa phương pháp và phạm vi áp dụng

### 2.2.6.1.1. Bản chất kinh tế lượng

Computes simplex-constrained model weights minimizing leave-one-out cross-validated squared error (JMA) or Mallows Cp criterion (MMA), achieving asymptotic optimality under heteroskedasticity.

### 2.2.6.1.2. Phạm vi áp dụng và yêu cầu cấu trúc dữ liệu

Nested or non-nested candidate regressor subsets where model selection uncertainty invalidates post-selection single-model inference.

- **Kiểm định tiền ước lượng bắt buộc**: `predictor_scale_collinearity_precheck, vif_multicollinearity`
- **Kiểm định hậu ước lượng bắt buộc**: `hansen_racine_jma_cv, aic_bic_information_criteria`

### 2.2.6.1.3. Hệ phương trình toán học và điều kiện định danh

Phương trình đặc tả cấu trúc của mô hình `mallows_jackknife_averaging`:

$$
\hat{\beta}(\lambda, \alpha) = \arg\min_{\beta \in \mathbb{R}^p} \left\{\frac{1}{2N}\|Y - X\beta\|_2^2 + \lambda \left(\alpha \|\beta\|_1 + \frac{1-\alpha}{2}\|\beta\|_2^2\right)\right\}
$$

Hàm mục tiêu tối ưu hóa và điều kiện mô-men thực nghiệm:

$$
\psi(W_i; \theta, \eta) = (Y_i - \ell_0(Z_i) - \theta(D_i - m_0(Z_i)))(D_i - m_0(Z_i)), \quad \mathbb{E}[\psi(W_i; \theta_0, \eta_0)] = 0
$$

Ma trận hiệp phương sai tiệm cận và đại lượng suy luận vững:

$$
\sqrt{N}(\hat{\theta} - \theta_0) \xrightarrow{d} \mathcal{N}\left(0, J_0^{-2}\mathbb{E}[\psi^2(W_i; \theta_0, \eta_0)]\right)
$$

# ==============================================================================
# BÀI 2.2.6 — MÃ BÀI B209: TRUNG BÌNH HÓA MÔ HÌNH TẦN SUẤT MALLOWS VÀ JACKKNIFE
# Môi trường: Python 3.11+ | Khóa mô hình: mallows_jackknife_averaging
# Tệp dữ liệu: vietlod_mallows_jackknife_averaging_ecodata.csv | Cỡ mẫu N = 160
# ==============================================================================
import pandas as pd

df = pd.read_csv("vietlod_mallows_jackknife_averaging_ecodata.csv")

# ECODATA replication & postestimation script - Mallows and Jackknife Frequentist Model Averaging (scipy::MallowsJackknifeModelAveraging)
# Family: regularized_high_dim / model_selection | Key: mallows_jackknife_averaging
import pandas as pd
# df: a pandas DataFrame holding your selected variables
import numpy as np, statsmodels.api as sm
from scipy.optimize import minimize
xs = ['x1', 'x2']; y = df["y"].values
errs, betas = [], []
for m in range(1, len(xs) + 1):
    Xm = sm.add_constant(df[xs[:m]]).values
    b = np.linalg.lstsq(Xm, y, rcond=None)[0]
    h = np.diag(Xm @ np.linalg.pinv(Xm.T @ Xm) @ Xm.T)
    errs.append((y - Xm @ b) / (1.0 - h))
E = np.column_stack(errs)
w = minimize(lambda w: float(w @ (E.T @ E) @ w), np.ones(len(xs))/len(xs), bounds=[(0,1)]*len(xs), constraints={"type":"eq","fun":lambda w: sum(w)-1}).x
print("JMA optimal weights:", w)
