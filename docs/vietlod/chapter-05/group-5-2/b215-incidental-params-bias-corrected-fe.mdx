## 5.2.5.1. Ý nghĩa phương pháp và phạm vi áp dụng

### 5.2.5.1.1. Bản chất kinh tế lượng

Removes O(1/T) Neyman-Scott incidental parameter bias via Dhaene-Jochmans half-panel jackknife theta_BC = 2*theta_full - 0.5*(theta_H1 + theta_H2) with entity-clustered covariance.

### 5.2.5.1.2. Phạm vi áp dụng và yêu cầu cấu trúc dữ liệu

Dynamic or nonlinear fixed-effects panels with moderate time dimension T &gt;= 4 where incidental parameters induce first-order asymptotic bias.

- **Kiểm định tiền ước lượng bắt buộc**: `hausman_fe_vs_re, pesaran_cd_cross_sectional_dependence`
- **Kiểm định hậu ước lượng bắt buộc**: `split_panel_jackknife_correction, wooldridge_panel_autocorrelation`

### 5.2.5.1.3. Hệ phương trình toán học và điều kiện định danh

Phương trình đặc tả cấu trúc của mô hình `incidental_params_bias_corrected_fe`:

$$
Y_{it} = \alpha_i + \lambda_t + X_{it}^\top \beta + \gamma^\top \bar{F}_t + \varepsilon_{it}, \quad i=1,\dots,N,\; t=1,\dots,T
$$

Hàm mục tiêu tối ưu hóa và điều kiện mô-men thực nghiệm:

$$
\mathbb{E}\left[Z_{i}^\top \Delta \varepsilon_i\right] = 0, \quad \hat{\beta}_{\text{GMM}} = \arg\min_{\beta} \left(\frac{1}{N}\sum_{i=1}^N Z_i^\top \Delta \varepsilon_i(\beta)\right)^\top W_N \left(\frac{1}{N}\sum_{i=1}^N Z_i^\top \Delta \varepsilon_i(\beta)\right)
$$

Ma trận hiệp phương sai tiệm cận và đại lượng suy luận vững:

$$
\widehat{\text{Var}}_{\text{CR}}(\hat{\beta}) = (X^\top M X)^{-1} \left(\sum_{i=1}^N X_i^\top M_i \hat{u}_i \hat{u}_i^\top M_i X_i\right) (X^\top M X)^{-1}
$$

# ==============================================================================
# BÀI 5.2.5 — MÃ BÀI B215: HIỆU ỨNG CỐ ĐỊNH HIỆU CHỈNH CHỆCH THAM SỐ NGẪU NHIÊN BẰNG TÁCH BẢNG JACKKNIFE
# Môi trường: Python 3.11+ | Khóa mô hình: incidental_params_bias_corrected_fe
# Tệp dữ liệu: vietlod_incidental_params_bias_corrected_fe_ecodata.csv | Cỡ mẫu N = 144
# ==============================================================================
import pandas as pd

df = pd.read_csv("vietlod_incidental_params_bias_corrected_fe_ecodata.csv")

# ECODATA replication & postestimation script - Split Panel Jackknife Bias Corrected Fixed Effects (statsmodels::SplitPanelJackknifeFE)
# Family: panel_data / dynamic | Key: incidental_params_bias_corrected_fe
import pandas as pd
# df: a pandas DataFrame holding your selected variables
import statsmodels.api as sm
yrs = sorted(df["year"].unique()); mid = len(yrs) // 2
def fe_b(sub):
    dy = sub["y"] - sub.groupby("entity")["y"].transform("mean")
    dX = sub[['x1', 'x2']] - sub.groupby("entity")[['x1', 'x2']].transform("mean")
    return sm.OLS(dy, dX).fit().params
b_bc = 2 * fe_b(df) - 0.5 * (fe_b(df[df["year"].isin(yrs[:mid])]) + fe_b(df[df["year"].isin(yrs[mid:])]))
print("Split-Panel Jackknife Bias-Corrected FE:", b_bc.to_dict())
