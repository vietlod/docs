## 3.1.6.1. Ý nghĩa phương pháp và phạm vi áp dụng

### 3.1.6.1.1. Bản chất kinh tế lượng

Identifies binary choice index parameters under conditional median restriction Med(u|X) = 0 without parametric error distribution assumptions, using Horowitz logistic-kernel smoothing for root-nh inference.

### 3.1.6.1.2. Phạm vi áp dụng và yêu cầu cấu trúc dữ liệu

Binary discrete outcomes with unknown heteroskedastic error forms where parametric Probit/Logit is inconsistent due to covariate-dependent error variance.

- **Kiểm định tiền ước lượng bắt buộc**: `outcome_separation_balance_precheck, vif_multicollinearity`
- **Kiểm định hậu ước lượng bắt buộc**: `manski_classification_score, hosmer_lemeshow_goodness_of_fit`

### 3.1.6.1.3. Hệ phương trình toán học và điều kiện định danh

Phương trình đặc tả cấu trúc của mô hình `maximum_score_manski`:

$$
U_{ij} = V_{ij}(X_{ij}, \beta_i) + \varepsilon_{ij}, \quad P_{ij} = \mathbb{P}\left(U_{ij} \ge U_{ik}, \forall k \in \mathcal{J}\right)
$$

Hàm mục tiêu tối ưu hóa và điều kiện mô-men thực nghiệm:

$$
\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} \sum_{i=1}^N \sum_{j \in \mathcal{J}} d_{ij} \ln P_{ij}(X_i; \theta)
$$

Ma trận hiệp phương sai tiệm cận và đại lượng suy luận vững:

$$
\widehat{\text{Var}}(\hat{\theta}) = \hat{H}(\hat{\theta})^{-1} \left(\sum_{i=1}^N \hat{s}_i(\hat{\theta})\hat{s}_i(\hat{\theta})^\top\right) \hat{H}(\hat{\theta})^{-1}
$$

df = pd.read_csv("vietlod_maximum_score_manski_ecodata.csv")

# ECODATA replication & postestimation script - Semiparametric Maximum Score Estimator Manski Horowitz (scipy::SmoothedMaximumScore)
# Family: discrete_choice / binary | Key: maximum_score_manski
import pandas as pd
# df: a pandas DataFrame holding your selected variables
import numpy as np, statsmodels.api as sm
from scipy.optimize import minimize
X = sm.add_constant(df[['x1', 'x2']]).values; y = df["y"].values
b0 = sm.Logit(y, X).fit(disp=False).params
h = len(y) ** (-0.2)
res = minimize(lambda b: -np.mean((2*y - 1) / (1 + np.exp(-(X @ b)/h))), b0, method="BFGS")
print("Horowitz Smoothed Maximum Score:", res.x)
