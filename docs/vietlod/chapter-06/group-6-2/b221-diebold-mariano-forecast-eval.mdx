## 6.2.7.1. Ý nghĩa phương pháp và phạm vi áp dụng

### 6.2.7.1.1. Bản chất kinh tế lượng

Evaluates out-of-sample predictive loss differentials d_t = L(e_\{1t\}) - L(e_\{2t\}) with Newey-West HAC long-run variance and Harvey-Leybourne-Newbold finite-sample Student-t adjustment.

### 6.2.7.1.2. Phạm vi áp dụng và yêu cầu cấu trúc dữ liệu

Comparing competing macroeconomic or financial forecasting specifications under quadratic, absolute, or asymmetric loss functions with serially correlated forecast errors.

- **Kiểm định tiền ước lượng bắt buộc**: `adf_unit_root, kpss_stationarity`
- **Kiểm định hậu ước lượng bắt buộc**: `diebold_mariano_hln, ljung_box_autocorrelation`

### 6.2.7.1.3. Hệ phương trình toán học và điều kiện định danh

Phương trình đặc tả cấu trúc của mô hình `diebold_mariano_forecast_eval`:

$$
\Phi(L)(1-L)^d Y_t = c + \Theta(L)\varepsilon_t + \sum_{j=0}^q \beta_j^\top X_{t-j}, \quad \varepsilon_t \sim \text{WN}(0, \sigma^2)
$$

Hàm mục tiêu tối ưu hóa và điều kiện mô-men thực nghiệm:

$$
\Delta Y_t = \alpha_0 + \rho Y_{t-1} + \theta^\top X_{t-1} + \sum_{j=1}^{p-1}\gamma_j \Delta Y_{t-j} + \sum_{j=0}^{q-1}\delta_j^\top \Delta X_{t-j} + u_t
$$

Ma trận hiệp phương sai tiệm cận và đại lượng suy luận vững:

$$
\widehat{\Omega}_{\text{HAC}} = \hat{\Gamma}_0 + \sum_{j=1}^m \left(1 - \frac{j}{m+1}\right)\left(\hat{\Gamma}_j + \hat{\Gamma}_j^\top\right)
$$

# ==============================================================================
# BÀI 6.2.7 — MÃ BÀI B221: MÔ HÌNH KIỂM ĐỊNH ĐỘ CHÍNH XÁC DỰ BÁO NGANG BẰNG DIEBOLD MARIANO

import pandas as pd

df = pd.read_csv("vietlod_diebold_mariano_forecast_eval_ecodata.csv")

# ECODATA replication & postestimation script - Diebold Mariano Equal Predictive Accuracy Test Model (statsmodels::DieboldMarianoForecastEval)
# Family: time_series / univariate | Key: diebold_mariano_forecast_eval
import pandas as pd
# df: a pandas DataFrame holding your selected variables
import numpy as np, statsmodels.api as sm
from scipy import stats
X = sm.add_constant(df[['x1', 'x2']]).values; y = df["y"].values
s = int(len(y) * 0.6)
e1 = np.array([y[t] - X[t] @ np.linalg.lstsq(X[:t], y[:t], rcond=None)[0] for t in range(s, len(y))])
e0 = np.array([y[t] - y[:t].mean() for t in range(s, len(y))])
d = e0**2 - e1**2; dm = d.mean() / (d.std(ddof=1) / np.sqrt(len(d)))
print("DM stat:", dm, "p-value:", 2 * stats.t.sf(abs(dm), df=len(d)-1))
