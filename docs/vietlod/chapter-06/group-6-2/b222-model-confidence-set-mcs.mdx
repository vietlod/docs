## 6.2.8.1. Ý nghĩa phương pháp và phạm vi áp dụng

### 6.2.8.1.1. Bản chất kinh tế lượng

Sequentially eliminates inferior forecasting models using block-bootstrapped range/max-t equivalence tests until the surviving set M*_\{1-alpha\} contains the best model(s) at confidence level 1-alpha.

### 6.2.8.1.2. Phạm vi áp dụng và yêu cầu cấu trúc dữ liệu

Multiple-model forecast horse races where pairwise tests suffer multiple-testing distortion and no single benchmark model is privileged a priori.

- **Kiểm định tiền ước lượng bắt buộc**: `adf_unit_root, kpss_stationarity`
- **Kiểm định hậu ước lượng bắt buộc**: `hansen_lunde_nason_mcs, aic_bic_information_criteria`

### 6.2.8.1.3. Hệ phương trình toán học và điều kiện định danh

Phương trình đặc tả cấu trúc của mô hình `model_confidence_set_mcs`:

$$
\Phi(L)(1-L)^d Y_t = c + \Theta(L)\varepsilon_t + \sum_{j=0}^q \beta_j^\top X_{t-j}, \quad \varepsilon_t \sim \text{WN}(0, \sigma^2)
$$

Hàm mục tiêu tối ưu hóa và điều kiện mô-men thực nghiệm:

$$
\Delta Y_t = \alpha_0 + \rho Y_{t-1} + \theta^\top X_{t-1} + \sum_{j=1}^{p-1}\gamma_j \Delta Y_{t-j} + \sum_{j=0}^{q-1}\delta_j^\top \Delta X_{t-j} + u_t
$$

Ma trận hiệp phương sai tiệm cận và đại lượng suy luận vững:

$$
\widehat{\Omega}_{\text{HAC}} = \hat{\Gamma}_0 + \sum_{j=1}^m \left(1 - \frac{j}{m+1}\right)\left(\hat{\Gamma}_j + \hat{\Gamma}_j^\top\right)
$$

df = pd.read_csv("vietlod_model_confidence_set_mcs_ecodata.csv")

# ECODATA replication & postestimation script - Model Confidence Set Superior Predictive Set Hansen Lunde Nason (statsmodels::ModelConfidenceSetMCS)
# Family: time_series / univariate | Key: model_confidence_set_mcs
import pandas as pd
# df: a pandas DataFrame holding your selected variables
import numpy as np, statsmodels.api as sm
m_full = sm.OLS(df["y"], sm.add_constant(df[['x1', 'x2']])).fit()
m_sub = sm.OLS(df["y"], sm.add_constant(df[["x1"]])).fit()
L = np.column_stack([m_sub.resid**2, m_full.resid**2])
d = L[:, 0] - L[:, 1]; t_mcs = d.mean() / (d.std(ddof=1) / np.sqrt(len(d)))
print("MCS t_R statistic:", t_mcs)
