## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Trong các chương trước, chúng ta đã làm quen và thành thạo với phương pháp Bình phương bé nhất thông thường - một công cụ cực kỳ mạnh mẽ. Tuy nhiên, OLS chỉ phát huy tác dụng khi các giả định của nó được thỏa mãn, đặc biệt là giả định các biến giải thích không tương quan với sai số. ## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_wsook10u1_c05_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_wsook10u1_c05_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_wsook10u1_c05_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
