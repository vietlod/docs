## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Hướng dẫn trình bày một nghiên cứu PLS-SEM hoàn chỉnh How to Write up a PLS-SEM Study Giới thiệu tổng quan về chuỗi bài học Chào mừng các bạn sinh viên đã đến với chuỗi bài học hướng dẫn cách viết và trình bày một bài báo khoa học sử dụng Mô hình bình phương nhỏ nhất riêng phần . Trong nghiên cứu khoa học, việc phân tích dữ liệu thành công chỉ là một nửa chặng đường. Nửa còn lại, và cũng không kém phần quan trọng, là khả năng trình bày các phát hiện của bạn một cách rõ ràng, logic và thuyết phục. Một bài viết được cấu trúc tốt không chỉ thể hiện sự chuyên nghiệp mà còn giúp người đọc dễ dàng

- **Chủ đề học thuật trọng tâm**: Giới thiệu tổng quan về chuỗi bài học, Cấu trúc chuỗi bài học, Kiến thức tiên quyết cần có, Mục tiêu học tập, Tài liệu tham khảo chính.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_msehk21u1_c08_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_msehk21u1_c08_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_msehk21u1_c08_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
