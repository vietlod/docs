## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu Mô hình hóa Phương trình Cấu trúc PLS-SEM An Introduction to PLS Structural Equation Modelling Tổng quan về Chuỗi bài học Mô hình PLS-SEM Chào mừng các bạn sinh viên đến với chuỗi bài học chuyên sâu về Mô hình hóa Phương trình Cấu trúc bằng Bình phương Tối thiểu Riêng phần, hay còn gọi là PLS-SEM . Trong thế giới nghiên cứu kinh tế và kinh doanh hiện đại, chúng ta thường xuyên phải đối mặt với những câu hỏi phức tạp không thể trả lời bằng các mô hình hồi quy truyền thống. ## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_msehk21u1_c03_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_msehk21u1_c03_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_msehk21u1_c03_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
