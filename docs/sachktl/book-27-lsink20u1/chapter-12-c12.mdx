## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu về quá trình thời gian liên tục An introduction to continuous time processes Chào các bạn sinh viên, chào mừng đến với chuỗi bài học về một trong những chủ đề hấp dẫn và mạnh mẽ nhất trong kinh tế lượng tài chính: các quá trình thời gian liên tục. Từ trước đến nay, chúng ta thường làm việc với dữ liệu chuỗi thời gian rời rạc, được thu thập theo ngày, tháng, hoặc quý. Tuy nhiên, trong thế giới tài chính hiện đại, các giao dịch diễn ra trong từng giây, từng mili giây. Làm thế nào để mô hình hóa sự biến động không ngừng nghỉ của giá cổ phiếu, tỷ giá hối đoái hay lãi suất? Câu trả lời

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_lsink20u1_c12_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_lsink20u1_c12_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_lsink20u1_c12_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
