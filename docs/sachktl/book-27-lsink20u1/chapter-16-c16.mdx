## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu các công cụ toán học nền tảng trong kinh tế lượng An introduction to foundational mathematical tools in econometrics Giới thiệu tổng quan Chào mừng các bạn sinh viên đã đến với chuỗi bài học đặc biệt, nơi chúng ta sẽ cùng nhau khám phá những công cụ toán học nền tảng nhưng lại vô cùng quyền năng, vốn là xương sống của rất nhiều mô hình kinh tế lượng hiện đại. ## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_lsink20u1_c16_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_lsink20u1_c16_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_lsink20u1_c16_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
