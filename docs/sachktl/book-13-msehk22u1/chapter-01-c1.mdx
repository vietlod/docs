## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Kết quả học tập mong đợi: Hiểu được nền tảng phương pháp luận của nghiên cứu thống kê. Nắm bắt được logic đằng sau các loại suy luận thống kê khác nhau. Hiểu tầm quan trọng của lý thuyết vững chắc. Nhận được một số gợi ý về cách viết các bài báo nghiên cứu định lượng và cách trình bày dữ liệu. Lý thuyết khoa học và phương pháp luận là những trụ cột mà các nhà khoa học xã hội dựa vào khi tiến hành nghiên cứu. Mục tiêu của nhà nghiên cứu khi sử dụng thống kê là rút ra các kết luận vượt xa dữ liệu thu thập được. Với các nghiên cứu có số lượng mẫu lớn, có thể đưa ra các khái quát về

- **Chủ đề học thuật trọng tâm**: Kết quả học tập mong đợi:, 1.1 Phương pháp luận của nghiên cứu thống kê, 1.2 Phương pháp thống kê, 1.3 Logic đằng sau suy luận thống kê, 1.3.1 Lý thuyết xác suất.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_msehk22u1_c01_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_msehk22u1_c01_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_msehk22u1_c01_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
