## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

11 Phân tích tổng hợp để đánh giá độ chính xác chẩn đoán Meta-Analysis for Evaluating Diagnostic Accuracy Một lĩnh vực chuyên biệt của phân tích tổng hợp Chào các bạn sinh viên, chào mừng đến với một chương mới đầy thách thức nhưng cũng vô cùng quan trọng trong nghiên cứu ứng dụng: Phân tích tổng hợp các nghiên cứu về Độ chính xác Chẩn đoán . Trong các bài học trước, chúng ta đã tập trung vào việc tổng hợp hiệu quả của các can thiệp, trả lời câu hỏi "Liệu phương pháp A có tốt hơn phương pháp B không?". Hôm nay, chúng ta sẽ chuyển sang một câu hỏi hoàn toàn khác, nhưng không kém phần cấp thiết

- **Chủ đề học thuật trọng tâm**: Một lĩnh vực chuyên biệt của phân tích tổng hợp, Cấu trúc chuỗi bài học, Kiến thức tiên quyết, Bạn cần chuẩn bị gì?, Mục tiêu học tập.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_cshek21u1_c11_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cshek21u1_c11_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cshek21u1_c11_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
