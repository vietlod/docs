## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu các chiến lược xử lý dữ liệu khuyết trong phân tích tổng hợp An Introduction to Strategies for Handling Missing data in Meta-Analysis Giới thiệu Đối mặt với thực tế của dữ liệu không hoàn hảo Trong thế giới nghiên cứu lý tưởng, chúng ta luôn có những bộ dữ liệu đầy đủ và hoàn hảo. Tuy nhiên, trong thực tế, dữ liệu khuyết là một vấn đề gần như không thể tránh khỏi. Từ các cuộc khảo sát mà người trả lời bỏ qua một vài câu hỏi, đến các nghiên cứu lâm sàng mà bệnh nhân bỏ dở giữa chừng, dữ liệu không hoàn chỉnh là một thách thức thường trực. Trong bối cảnh của phân tích tổng hợp, vấn

- **Chủ đề học thuật trọng tâm**: Giới thiệu Đối mặt với thực tế của dữ liệu không hoàn hảo, Cấu trúc chuỗi bài học về xử lý dữ liệu khuyết, Kiến thức tiên quyết cần chuẩn bị, Mục tiêu học tập của chuỗi bài viết, Tài liệu tham khảo chính.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_cshek21u1_c10_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cshek21u1_c10_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cshek21u1_c10_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
