## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu Phân tích tổng hợp đa biến An Introduction to Multivariate Meta-Analysis Giới thiệu Vượt ra ngoài phân tích đơn biến Trong các chuỗi bài học trước, chúng ta đã thành thạo các kỹ thuật phân tích tổng hợp đơn biến , nơi chúng ta tập trung vào việc tổng hợp một biến kết quả duy nhất qua nhiều nghiên cứu. Tuy nhiên, trong thực tế, các nghiên cứu thường đo lường nhiều hơn một kết quả. Ví dụ, một chính sách kinh tế mới có thể ảnh hưởng đồng thời đến cả tỷ lệ tăng trưởng GDP và tỷ lệ thất nghiệp; một liệu pháp y tế có thể tác động đến cả huyết áp và mức cholesterol. Các kết quả này thường

- **Chủ đề học thuật trọng tâm**: Giới thiệu Vượt ra ngoài phân tích đơn biến, Cấu trúc chuỗi bài học về phân tích tổng hợp đa biến, Kiến thức tiên quyết cần chuẩn bị, Mục tiêu học tập của chuỗi bài viết, Tài liệu tham khảo chính.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_cshek21u1_c08_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cshek21u1_c08_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cshek21u1_c08_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
