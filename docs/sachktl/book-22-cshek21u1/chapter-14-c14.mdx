## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu phân tích tổng hợp: Dữ liệu bệnh nhân cá nhân và dữ liệu tóm tắt An Introduction to Meta-Analysis: Individual Patient-Level data vs. Summary Sstatistics Giới thiệu Cuộc tranh luận về "tiêu chuẩn vàng" Trong thế giới của phân tích tổng hợp, việc có được dữ liệu cấp độ bệnh nhân cá nhân từ các nghiên cứu gốc thường được coi là "tiêu chuẩn vàng". Về mặt lý thuyết, việc phân tích dữ liệu thô cho phép chúng ta thực hiện các mô hình phức tạp hơn, kiểm tra các tương tác ở cấp độ cá nhân, và chuẩn hóa các biến số một cách nhất quán, hứa hẹn mang lại các kết quả

- **Chủ đề học thuật trọng tâm**: Giới thiệu Cuộc tranh luận về "tiêu chuẩn vàng", Cấu trúc chuỗi bài học: Đối đầu hai phương pháp, Kiến thức tiên quyết cần chuẩn bị, Mục tiêu học tập của chuỗi bài viết, Tài liệu tham khảo chính.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_cshek21u1_c14_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cshek21u1_c14_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cshek21u1_c14_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
