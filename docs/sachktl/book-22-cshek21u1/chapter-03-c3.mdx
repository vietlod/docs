## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu phân tích tổng hợp với mô hình hiệu ứng cố định và ngẫu nhiên An Introduction to Meta-Analysis with Fixed-Effects and Random-Effects models Giới thiệu tổng quan về chuỗi bài học phân tích tổng hợp Trong nghiên cứu khoa học, đặc biệt là trong các lĩnh vực y tế, kinh tế và khoa học xã hội, chúng ta thường xuyên đối mặt với một tình huống phổ biến: có rất nhiều nghiên cứu đã được thực hiện về cùng một chủ đề, nhưng kết quả của chúng lại không hoàn toàn giống nhau, đôi khi còn mâu thuẫn. Vậy làm thế nào để chúng ta có thể đưa ra một kết luận tổng thể, đáng tin cậy từ tất cả các bằng

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_cshek21u1_c03_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cshek21u1_c03_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cshek21u1_c03_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
