## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu chuỗi bài học về mô hình chuỗi thời gian không dừng An Introduction to Nonstationary Time Series models Chào mừng các nhà kinh tế lượng tương lai Chào mừng các bạn sinh viên đã đến với một trong những chủ đề hấp dẫn và thực tiễn nhất trong kinh tế lượng: phân tích chuỗi thời gian không dừng. Nếu các bạn từng nhìn vào biểu đồ GDP, giá cổ phiếu, hay dân số và thấy chúng có xu hướng tăng mãi theo thời gian, thì các bạn đã bắt gặp chuỗi không dừng rồi đấy. Dữ liệu kinh tế trong thực tế hiếm khi "đứng yên", chúng luôn vận động, tăng trưởng, và thay đổi. Việc phân tích các chuỗi dữ liệu

- **Chủ đề học thuật trọng tâm**: Chào mừng các nhà kinh tế lượng tương lai, Cấu trúc chuỗi bài học, KIẾN THỨC TIÊN QUYẾT, MỤC TIÊU HỌC TẬP, TÀI LIỆU THAM KHẢO.
- **Môi trường phần mềm thực hành**: `Stata 18 MP, R 4.x`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_sseak20u1_c10_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_sseak20u1_c10_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_sseak20u1_c10_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
