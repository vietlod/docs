## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Mô hình ARCH và GARCH cho người bắt đầu Time-varying Volatility models from Scratch Giới thiệu tổng quan Chào mừng các bạn sinh viên đến với chuỗi bài học chuyên sâu về một trong những chủ đề hấp dẫn nhất của kinh tế lượng chuỗi thời gian: mô hình hóa sự biến động. Trong thế giới thực, đặc biệt là trong tài chính và kinh tế vĩ mô, chúng ta thường quan sát thấy các giai đoạn "sóng yên biển lặng" xen kẽ với những thời kỳ "bão tố" dữ dội. Ví dụ, thị trường chứng khoán có thể ổn định trong nhiều tháng, rồi đột ngột biến động mạnh sau một sự kiện bất ngờ. Các mô hình ARIMA tiêu chuẩn mà chúng ta

- **Chủ đề học thuật trọng tâm**: Giới thiệu tổng quan, CẤU TRÚC CHUỖI BÀI HỌC, KIẾN THỨC TIÊN QUYẾT, MỤC TIÊU HỌC TẬP, TÀI LIỆU THAM KHẢO.
- **Môi trường phần mềm thực hành**: `Stata 18 MP, R 4.x`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_sseak20u1_c08_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_sseak20u1_c08_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_sseak20u1_c08_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
