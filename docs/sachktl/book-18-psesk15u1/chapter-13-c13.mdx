## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu tổng quan về phân tích phổ An Introduction to Spectral Analysis TÓM TẮT CHỦ ĐỀ Chào các bạn sinh viên, trong các học phần kinh tế lượng trước đây, chúng ta đã quen thuộc với việc phân tích chuỗi thời gian trong miền thời gian. Chúng ta xem xét mối quan hệ của một biến theo các giá trị trễ của chính nó, ví dụ như trong các mô hình ARMA. Tuy nhiên, có một cách tiếp cận hoàn toàn khác nhưng vô cùng mạnh mẽ, đó là phân tích trong miền tần số . Phân tích phổ chính là công cụ cốt lõi của phương pháp này. Hãy tưởng tượng một chuỗi thời gian, ví dụ như GDP hàng quý, không

- **Môi trường phần mềm thực hành**: `Stata 18 MP`.

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_psesk15u1_c13_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_psesk15u1_c13_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_psesk15u1_c13_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
