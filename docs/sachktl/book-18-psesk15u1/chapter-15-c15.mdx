## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Quá trình nghiệm đơn vị Unit root process TẠI SAO NGHIỆM ĐƠN VỊ LÀ "KẺ PHÁ BĨNH" TRONG KINH TẾ LƯỢNG? Trong kinh tế lượng, một trong những giả định nền tảng khi làm việc với dữ liệu chuỗi thời gian là tính dừng. Một chuỗi được gọi là dừng nếu các đặc tính thống kê của nó, như giá trị trung bình và phương sai, không thay đổi theo thời gian. Hãy tưởng tượng bạn đang phân tích dữ liệu GDP hàng quý. Nếu chuỗi GDP là dừng, chúng ta có thể tự tin rằng mối quan hệ chúng ta tìm thấy hôm nay vẫn sẽ đúng trong tương lai. Tính dừng mang lại sự ổn định và khả năng dự báo cho mô hình. Tuy

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_psesk15u1_c15_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_psesk15u1_c15_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_psesk15u1_c15_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
