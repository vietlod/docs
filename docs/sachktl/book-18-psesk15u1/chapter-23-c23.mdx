## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu mô hình VARX cho người bắt đầu An Introduction to VARX Modelling for Beginners Chào các bạn sinh viên, chào mừng đến với chuỗi bài học chuyên sâu về Mô hình VARX . Trong kinh tế lượng, chúng ta thường bắt đầu với mô hình VAR để phân tích mối quan hệ tương tác giữa nhiều biến. Tuy nhiên, thực tế thường phức tạp hơn: có những biến số bên ngoài tác động mạnh mẽ đến kinh tế trong nước, nhưng bản thân chúng lại ít bị ảnh hưởng ngược lại trong dài hạn. ## 3. Minh họa kịch bản thực hành trên Stata, R và Python

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_psesk15u1_c23_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_psesk15u1_c23_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_psesk15u1_c23_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
