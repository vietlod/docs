## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Kiểm định mô hình phương trình cấu trúc để xác nhận lý thuyết nghiên cứu Testing Structural Equation Models to Confirm Research Theories Giới thiệu tổng quan về mô hình phương trình cấu trúc Chào mừng các bạn đã đến với chuỗi bài học chuyên sâu về một trong những kỹ thuật phân tích mạnh mẽ và phổ biến nhất trong kinh tế lượng và khoa học xã hội: Mô hình Phương trình Cấu trúc, hay còn gọi là SEM . Nếu bạn đã từng tự hỏi làm thế nào để kiểm định một lý thuyết phức tạp với nhiều mối quan hệ chồng chéo, ví dụ như "Sự hài lòng trong công việc" và "Môi trường làm việc" cùng tác động đến "Cam

- **Chủ đề học thuật trọng tâm**: Giới thiệu tổng quan về mô hình phương trình cấu trúc, Cấu trúc chuỗi bài học về kiểm định mô hình cấu trúc, Kiến thức tiên quyết cần chuẩn bị, Yêu cầu kiến thức, Mục tiêu học tập của chuỗi bài viết.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_hsaik19u1_c11_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_hsaik19u1_c11_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_hsaik19u1_c11_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
