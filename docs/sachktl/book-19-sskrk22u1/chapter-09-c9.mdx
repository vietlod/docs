## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu chuỗi bài học về mô hình hiệu ứng ngẫu nhiên chéo An Introduction to the Crossed Random-Effects models series Tổng quan về chuỗi bài học Chào mừng các bạn sinh viên đến với một chương mới đầy thú vị trong hành trình khám phá các mô hình đa cấp! Trong các chuỗi bài học trước, chúng ta đã tập trung vào các mô hình phân cấp hay mô hình lồng nhau . Đây là những cấu trúc dữ liệu rất trật tự, giống như những con búp bê Nga: học sinh được lồng trong các lớp học, và các lớp học lại được lồng trong các trường học. ## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_sskrk22u1_c09_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_sskrk22u1_c09_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_sskrk22u1_c09_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
