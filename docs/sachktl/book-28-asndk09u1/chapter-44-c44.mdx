## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu về Lọc Hạt trong kinh tế lượng An Introduction to Particle Filtering in Econometrics Tổng quan về chuỗi bài học Chào các bạn sinh viên, chào mừng đến với chuỗi bài học chuyên sâu về một trong những kỹ thuật hiện đại và mạnh mẽ nhất trong kinh tế lượng chuỗi thời gian: Lọc Hạt . Những yếu tố này được gọi là các biến ẩn , và việc ước tính chúng

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

```stata

version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_asndk09u1_c44_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_asndk09u1_c44_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```
