## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Tổng quan về hồi quy bán tham số trong kinh tế lượng An Overview of Semiparametric Regression in Econometrics Giới thiệu về hồi quy bán tham số và tầm quan trọng Chào mừng các bạn đến với chuỗi bài học chuyên sâu về hồi quy bán tham số, một trong những công cụ mạnh mẽ và linh hoạt nhất trong kho tàng kinh tế lượng hiện đại. Trong các chương trước, chúng ta đã làm quen với các mô hình hồi quy tham số, chẳng hạn như OLS, vốn yêu cầu chúng ta phải xác định trước một dạng hàm cụ thể cho mối quan hệ giữa các biến. Tuy nhiên, trong thực tế, các mối quan hệ kinh tế thường phức tạp hơn nhiều và không

- **Chủ đề học thuật trọng tâm**: Giới thiệu về hồi quy bán tham số và tầm quan trọng, Cấu trúc chuỗi bài học, Kiến thức tiên quyết, Mục tiêu học tập, Tài liệu tham khảo.

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_csamk22u1_c30_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_csamk22u1_c30_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_csamk22u1_c30_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
