## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Các phương pháp dựa trên lựa chọn các biến không quan sát được Chào mừng các bạn sinh viên đã quay trở lại với chuỗi bài học về kinh tế lượng đánh giá chương trình! Ở chương trước, chúng ta đã cùng nhau tìm hiểu các phương pháp xử lý "thiên lệch công khai", tức là những sai lệch gây ra bởi các yếu tố mà chúng ta có thể quan sát và đo lường được trong bộ dữ liệu. Tuy nhiên, trong thực tế, bài toán khó khăn và phổ biến hơn rất nhiều là khi quyết định tham gia một chương trình lại phụ thuộc vào những yếu tố mà chúng ta không thể thấy được, chẳng hạn như năng lực bẩm sinh, động lực

- **Chủ đề học thuật trọng tâm**: Cấu trúc chuỗi bài học.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_cserk22u1_c03_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cserk22u1_c03_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cserk22u1_c03_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
