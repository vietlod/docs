## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Mô hình các mối quan hệ dài hạn trong tài chính Chào mừng các bạn sinh viên đến với chuỗi bài học chuyên sâu về một trong những chủ đề hấp dẫn và quan trọng nhất trong kinh tế lượng tài chính: mô hình hóa các mối quan hệ dài hạn. Có bao giờ bạn tự hỏi tại sao khi hồi quy hai chuỗi dữ liệu thời gian , chúng ta lại nhận được kết quả R-bình phương rất cao nhưng thực chất lại vô nghĩa không? Đó chính là hiện tượng "hồi quy giả" - một cái bẫy phổ biến mà rất nhiều nhà phân tích trẻ gặp phải. Chuỗi bài học này sẽ trang bị cho các bạn kiến thức nền tảng và công cụ cần thiết để tránh những sai lầm đó

- **Chủ đề học thuật trọng tâm**: PHỤ LỤC: Dữ liệu mô phỏng cho chuỗi bài viết.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

```stata
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_bsrok19u1_c08_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_bsrok19u1_c08_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_bsrok19u1_c08_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
```
