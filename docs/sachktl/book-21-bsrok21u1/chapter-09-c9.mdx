## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Các vấn đề nền tảng và ứng dụng mở rộng trong phân tích tổng hợp Foundational Issues and Extended Applications in Meta-Analysis Tóm tắt nội dung chuỗi bài viết Chào các bạn sinh viên, trong hai chuỗi bài học trước, chúng ta đã cùng nhau xây dựng một nền tảng vững chắc về cách thực hiện và diễn giải một phân tích tổng hợp, từ việc tính toán hiệu ứng trung bình đến việc khám phá tính không đồng nhất. Giờ đây, đã đến lúc chúng ta đào sâu hơn vào "phòng máy" của phương pháp này, để hiểu rõ hơn về những nguyên tắc nền tảng định hình nên cách chúng ta làm việc và những cánh cửa mới mà phương pháp

- **Chủ đề học thuật trọng tâm**: Tóm tắt nội dung chuỗi bài viết, Cấu trúc chuỗi bài học, Kiến thức tiên quyết, Mục tiêu học tập, Phụ lục: Dữ liệu mô phỏng cho Nghịch lý Simpson.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_bsrok21u1_c09_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_bsrok21u1_c09_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_bsrok21u1_c09_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
