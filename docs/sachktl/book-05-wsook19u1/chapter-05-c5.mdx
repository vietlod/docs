## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Phân tích hồi quy bội: Các tính chất tiệm cận của OLS Chào các bạn sinh viên, chào mừng đến với một trong những chương quan trọng nhất trên hành trình chinh phục kinh tế lượng của chúng ta. Trong các bài học trước, chúng ta đã làm quen với các ước lượng OLS và các tính chất của chúng trong "mẫu hữu hạn" – tức là với một bộ dữ liệu có kích thước cụ thể. Nhưng điều gì sẽ xảy ra khi chúng ta có rất, rất nhiều dữ liệu? Liệu các kết luận của chúng ta có trở nên đáng tin cậy hơn không? ## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_wsook19u1_c05_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_wsook19u1_c05_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_wsook19u1_c05_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
