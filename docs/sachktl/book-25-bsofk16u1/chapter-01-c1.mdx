## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu chuỗi thời gian tài chính Chuỗi thời gian tài chính là một trong những lĩnh vực quan trọng nhất của kinh tế lượng hiện đại. Khác với dữ liệu kinh tế truyền thống, dữ liệu tài chính có những đặc điểm riêng biệt như tính biến động cao, hiệu ứng phân cụm biến động , và sự vi phạm giả định phân phối chuẩn. Hiểu rõ và mô hình hóa chính xác các đặc điểm này là chìa khóa để đưa ra các quyết định đầu tư và quản lý rủi ro hiệu quả. Series bài viết này sẽ hướng dẫn bạn từ những khái niệm cơ bản nhất về chuỗi thời gian tài chính đến các mô hình phức tạp như GARCH, sử dụng phần mềm Stata để

- **Chủ đề học thuật trọng tâm**: Cấu trúc series bài viết, Kiến thức tiên quyết, Các khái niệm chính, Tại sao nghiên cứu chuỗi thời gian tài chính?, Tài liệu tham khảo chính.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_bsofk16u1_c01_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_bsofk16u1_c01_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_bsofk16u1_c01_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
