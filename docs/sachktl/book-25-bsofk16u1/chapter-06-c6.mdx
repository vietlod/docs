## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Giới thiệu phân tích lây lan tài chính trong Kinh tế lượng Phân tích lây lan tài chính là một chủ đề quan trọng trong kinh tế lượng tài chính, nghiên cứu cách thức các cú sốc tài chính lan truyền giữa các thị trường và quốc gia khác nhau. Chủ đề này trở nên đặc biệt quan trọng sau các cuộc khủng hoảng tài chính toàn cầu như khủng hoảng châu Á 1997-1998 và khủng hoảng tài chính 2008-2009. Series bài viết này dựa trên Chương 6 từ tác phẩm "A Practitioner's Guide to Financial Econometrics Using Stata" của Boffelli và Urga, cung cấp hướng dẫn thực hành chi tiết về ba phương pháp chính để

- **Chủ đề học thuật trọng tâm**: Tổng quan về cấu trúc series, Tạo dữ liệu mô phỏng cho thực hành, Kiến thức tiên quyết, Các khái niệm then chốt, Ý nghĩa thực tiễn.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_bsofk16u1_c06_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_bsofk16u1_c06_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_bsofk16u1_c06_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
