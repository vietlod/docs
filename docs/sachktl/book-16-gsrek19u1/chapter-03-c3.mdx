## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Hồi quy bình phương nhỏ nhất Giới thiệu chuỗi bài học Chào mừng các bạn sinh viên đến với chuỗi bài học nền tảng và quan trọng nhất trong kinh tế lượng: Hồi quy Bình phương nhỏ nhất, hay còn gọi là OLS . Đây là công cụ mạnh mẽ giúp chúng ta "vẽ" một đường thẳng phù hợp nhất qua các điểm dữ liệu, từ đó lượng hóa các mối quan hệ kinh tế phức tạp trong thế giới thực, chẳng hạn như giáo dục ảnh hưởng đến thu nhập như thế nào, hay lãi suất tác động ra sao đến quyết định đầu tư của doanh nghiệp. Trong chuỗi bài này, chúng ta sẽ cùng nhau đi từ những ý tưởng trực quan nhất đến việc nắm vững các công

- **Chủ đề học thuật trọng tâm**: Giới thiệu chuỗi bài học, Cấu trúc chuỗi bài học, Kiến thức tiên quyết cần chuẩn bị, Mục tiêu học tập sau chuỗi bài, Tài liệu tham khảo chính.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_gsrek19u1_c03_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_gsrek19u1_c03_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_gsrek19u1_c03_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
