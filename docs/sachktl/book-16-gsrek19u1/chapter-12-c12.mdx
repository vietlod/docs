## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Khung ước lượng trong kinh tế lượng Giới thiệu tổng quan Chào mừng các bạn sinh viên đến với chuỗi bài học về các phương pháp ước lượng trong kinh tế lượng! Trong thực tế, khi phân tích dữ liệu, chúng ta có rất nhiều công cụ để lựa chọn, từ những phương pháp yêu cầu các giả định chặt chẽ về mặt lý thuyết đến những kỹ thuật linh hoạt hơn, đòi hỏi ít giả định hơn. Việc lựa chọn phương pháp nào cho phù hợp có thể là một thách thức, ngay cả với những nhà nghiên cứu có kinh nghiệm. Chuỗi bài học này được thiết kế để trang bị cho các bạn một cái nhìn tổng quan, giúp các bạn hiểu rõ bản chất, ưu và

- **Chủ đề học thuật trọng tâm**: Giới thiệu tổng quan, Cấu trúc chuỗi bài học, Kiến thức tiên quyết cần chuẩn bị, Mục tiêu học tập của chuỗi bài viết, Tài liệu tham khảo chính.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

```stata

version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_gsrek19u1_c12_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_gsrek19u1_c12_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_gsrek19u1_c12_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
