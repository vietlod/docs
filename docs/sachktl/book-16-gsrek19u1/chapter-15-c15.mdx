## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Ước lượng và suy luận dựa trên mô phỏng và mô hình tham số ngẫu nhiên Chào các bạn sinh viên, trong hành trình chinh phục kinh tế lượng, chúng ta thường làm việc với các mô hình có thể giải được bằng những công thức toán học gọn gàng. Tuy nhiên, thế giới kinh tế thực tế lại vô cùng phức tạp, đòi hỏi những mô hình linh hoạt hơn – những mô hình mà đôi khi không thể giải quyết bằng các phương pháp giải tích truyền thống. Vậy chúng ta phải làm gì khi đối mặt với những thách thức đó? Câu trả lời nằm ở một trong những công cụ mạnh mẽ nhất của kinh tế lượng hiện đại: phương pháp dựa trên mô phỏng.

- **Chủ đề học thuật trọng tâm**: Cấu trúc chuỗi bài học, Kiến thức tiên quyết, Mục tiêu học tập, Tài liệu tham khảo, PHỤ LỤC: Dữ liệu mô phỏng cho chuỗi bài viết.
- **Môi trường phần mềm thực hành**: `Stata 18 MP`.
- **Nguồn dữ liệu thực nghiệm khuyến nghị**: Kho dữ liệu vĩ mô, doanh nghiệp và khảo sát Việt Nam tại [EcoData](https://ecodata.io.vn), dữ liệu thị trường tài chính và hàng hóa tại [Finco](https://www.finco.vn), đối chiếu mô hình tại [VietLOD](https://vietlod.tnsai.vn) và tự động hóa ước lượng tại [EcoLab](https://ecolab.io.vn).

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_gsrek19u1_c15_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_gsrek19u1_c15_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_gsrek19u1_c15_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
