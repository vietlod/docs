## 1. Ý nghĩa phương pháp luận và phạm vi áp dụng

Ước lượng M Chào mừng các bạn sinh viên đến với một trong những chủ đề nền tảng và mạnh mẽ nhất của kinh tế lượng hiện đại: M-Estimators. Trong các học phần nhập môn, chúng ta đã quen thuộc với ước lượng Bình phương bé nhất, một công cụ tuyệt vời có công thức đại số rõ ràng. Tuy nhiên, thế giới kinh tế không phải lúc nào cũng tuyến tính. Rất nhiều mô hình phức tạp và thực tế hơn—như Probit, Logit, hay Hồi quy phân vị—không có công thức nghiệm đơn giản. Vậy làm thế nào để chúng ta ước lượng và suy diễn từ chúng một cách đáng tin cậy? Câu trả lời nằm ở M-Estimators, một "gia đình" lớn bao

## 3. Minh họa kịch bản thực hành trên Stata, R và Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Thiết lập môi trường và nạp dữ liệu thực hành từ EcoData / SachKTL
version 18.0
clear all
set more off

* Nạp bộ dữ liệu thực nghiệm chuẩn hóa
import delimited "sachktl_hsank22u1_c22_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Ước lượng mô hình và kiểm định chẩn đoán với sai số chuẩn vững
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Nạp thư viện phân tích định lượng và dữ liệu thực hành từ EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_hsank22u1_c22_ecodata.csv")
summary(df)

# Ước lượng mô hình và xuất sai số chuẩn vững HC1
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Nạp thư viện kinh tế lượng và bộ dữ liệu thực hành từ EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_hsank22u1_c22_ecodata.csv")
print(df.describe())

# Ước lượng mô hình với sai số chuẩn vững HC1
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
