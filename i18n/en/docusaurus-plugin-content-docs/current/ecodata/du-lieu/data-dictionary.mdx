# Data Dictionary and Academic Short Code System

This reference defines the **metadata schema** of EcoData: every economic and financial indicator is documented through standardized fields so researchers can discover, cite, and reproduce empirical studies with full transparency.

## Metadata Schema of an Indicator

Every indicator in EcoData carries the following standardized fields:

| Field Name | Academic and Technical Definition | Representative Example |
| --- | --- | --- |
| `short_code` | EcoData four-segment standardized academic identifier | `wb_mac_gdp_usd` |
| `code` | Native indicator code published by the originating institution | `NY.GDP.MKTP.CD`, `GRDP_34`, `STATE_BUDGET` |
| `label_vi` and `label_en` | Curated bilingual Vietnamese and English indicator titles | Gross Domestic Product in current USD |
| `unit` | Original unit of measurement | `USD`, `% of GDP`, `billion VND`, `thousand persons`, `tons` |
| `frequency` | Observation frequency of the series | `annual`, `quarterly`, `monthly`, `mixed` |
| `source` | Originating agency or domestic subsystem | World Bank, IMF, National Statistics, State Budget, Socio-Economic Reports, Vietnam Customs, Governance Indices, Commodity Market |
| `boundary_mode` | Vietnam provincial administrative boundary regime | `"63"` for 63 historical provinces; `"34"` for 34 provinces under Resolution 202/2025/QH15 |
| `aggregation_rule` | Mathematical rule aggregating 63 provinces into 34 provinces | additive scale summation, denominator-weighted average, constant-price scale growth recomputation, index chaining, non-aggregable observation preservation |
| `time_start` and `time_end` | First and last available observation period | `1995` / `2026` |
| `spatial_coverage` | Geographic or institutional unit of analysis | Country, 63 provinces, 34 provinces, listed firm, household |
| `source_footnotes` | Collapsible primary data source footnote with source badges | Source tables from the National Statistics Office, Ministry of Finance, and Vietnam Customs, update cadence, and boundary notes |

:::tip Dual Lookup by Short Code and Native Code
Researchers can search by **`short_code`** for compact, stable modeling or by the agency's native **`code`**. The interface prioritizes `short_code` while preserving the native code in metadata for source verification.
:::

## Academic Short Code System `ss_dom_key_mod`

EcoData maps lengthy, heterogeneous agency codes into a **structured four-segment academic short code** up to 18 characters separated by underscores:

```text
ss _ dom _ key _ mod
│    │     │     └── mod: measurement unit or transformation such as usd, pct, idx, cap
│    │     └──────── key: core economic concept such as gdp, cpi, exp, pop
│    └────────────── dom: substantive domain such as mac, ext, fis, lab, dem
└─────────────────── ss: originating agency such as wb, im, ad, un, fr, gs
```

| Segment | Identification Role | Representative Values |
| --- | --- | --- |
| `ss` | Data Source | `wb` World Bank, `im` IMF, `ad` ADB, `un` United Nations, `fr` FRED, `gs` National Statistics Office |
| `dom` | Economic Domain | `mac` macroeconomics, `ext` external sector, `fis` fiscal budget, `lab` labor market, `dem` demographics |
| `key` | Core Indicator Concept | `gdp`, `grdp`, `cpi`, `exp`, `imp`, `pop`, `une`, `fdi` |
| `mod` | Unit or Variant | `usd`, `vnd`, `pct`, `idx`, `cap` per capita |

### Academic Short Code Mapping Examples

| Native Agency Code | EcoData `short_code` | Full Semantic Meaning |
| --- | --- | --- |
| `NY.GDP.MKTP.CD` | `wb_mac_gdp_usd` | World Bank · Macroeconomics · GDP · Current USD |
| `FP.CPI.TOTL.ZG` | `wb_mac_cpi_pct` | World Bank · Macroeconomics · CPI Inflation · Annual Percentage |
| `SL.UEM.TOTL.ZS` | `wb_lab_une_pct` | World Bank · Labor · Unemployment Rate · Percentage of Labor Force |

## 34-Province Boundary Harmonization and Finco Subsystem Terms

| Technical Term | Standard Definition in EcoData |
| --- | --- |
| `boundary_mode` | Parameter toggling between `"63"` historical provinces and `"34"` consolidated provinces and cities under Resolution 202/2025/QH15 across the web UI and all 37 MCP tools. |
| **34-Province Harmonized Series** | Database table storing harmonized 2000–2026 provincial time series for all 34 consolidated provinces reconstructed under five mathematical rules without mutating 63-province tables. |
| **34-Province Administrative Crosswalk** | Official crosswalk table mapping 63 historical provinces to 34 consolidated provinces, including administrative centers and constituent province lists. |
| **34-Province Yearbook Appendices** | Fourteen official 2024 Statistical Yearbook Appendices published by the National Statistics Office under the 34-province structure, used as the 99.5% or higher reconciliation benchmark. |
| **State Budget Revenue and Expenditure** | Ministry of Finance state budget revenue and expenditure dataset code covering 1995 to 2026 in the State Budget subsystem. |
