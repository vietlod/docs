# Quick Start Workflow on EcoData

A six-step workflow to go from opening the application to obtaining a publication-ready dataset with econometric estimations and replication scripts. The interactive guide inside the web app is available at [ecodata.io.vn/quick-start](https://ecodata.io.vn/quick-start).

## 1. Log In and Initialize Your Workspace

Log in with email or Google OAuth. Once authenticated, you land on the **Main Dashboard** where you search international macro indicators and access Vietnam data modules. Browsing the catalog and previewing series are free; full dataset exports and EcoData MCP Server connections require a paid subscription tier.

→ Details: [Login, Filter, Preview, and Export Workflow](/ecodata/bat-dau/login-filter-preview-export)

## 2. Explore Data Sources and Seven Finco Subsystems

Choose your data subsystem based on the **unit of analysis** of your research question:

| Research Need | Subsystem and App Module | Documentation Link |
| --- | --- | --- |
| Cross-country comparison and eight focus regions `MAIN_MARKET` | Global Data on Dashboard | [Global Data](/ecodata/indicators/global-data) |
| Vietnam official statistics across 63 or 34 provinces `NSO`, `FISCAL`, `KTXH_GSO`, `VN_34_REBUILD` | GSO Explorer with **[63 Provinces \| 34 Provinces]** toggle | [Vietnam GSO and 34-Province Series](/ecodata/indicators/gso-vietnam) |
| Merchandise trade across 11 `CUSTOMS` forms and five-sector `COMMODITY_MARKET` | Customs Explorer | [Customs and Commodity Intelligence](/ecodata/indicators/customs) |
| Provincial governance indices `SURVEY_INDEX` covering PCI, PGI, PAPI, PII, PAR, SIPAS, ICT | Survey Explorer | [Macro Survey and VHLSS](/ecodata/indicators/macro-survey-vhlss) |
| Household living standards microdata VHLSS | VHLSS Variable Hub | [Macro Survey and VHLSS](/ecodata/indicators/macro-survey-vhlss) |
| Stock prices, 30-year financial statements across four accounting regimes, and corporate events | Stock Hub | [Stock Hub](/ecodata/indicators/stock-hub) |

→ Overview: [Data Source Groups](/ecodata/nguon-du-lieu/phan-nhom-nguon-du-lieu)

## 3. Select and Filter Indicators by Academic Short Code

1. Enter an English or Vietnamese **keyword** or an **academic short code** such as `wb_mac_gdp_usd`.
2. Filter by **issuing organization** or domestic subsystem such as `NSO`, `FISCAL`, `KTXH_GSO`, `CUSTOMS`, or `COMMODITY_MARKET`.
3. Select the **administrative boundary mode** for Vietnam provincial data: **63 provinces** for historical administrative boundaries or **34 provinces** under Resolution 202/2025/QH15 for harmonized 1995–2026 series.
4. Choose the **frequency** across annual, quarterly, or monthly series and set your target **year range**.
5. Prioritize indicators with high **completeness**.

→ Field concepts: [Data Dictionary](/ecodata/du-lieu/data-dictionary)

## 4. Preview Series and Primary Data Source Footnotes

Before downloading the full dataset, verify four elements: **spatial and temporal coverage**, **measurement units**, **34-province aggregation rule** such as `sum`, `weighted_mean`, or `growth_constant_scale`, and expand the **Primary Data Source Footnotes** panel at the bottom of the view to confirm official source codes such as `PLV01..PLV14` or `THUCHINS`.

→ Why it matters: [Data Methodology](/ecodata/du-lieu/methodology)

## 5. Export Standardized Datasets With Metadata

Export datasets to **CSV, Excel, or JSON** in either Wide matrix or Long time-series format, always bundled with **provenance metadata and academic short codes**.

→ Formats and limits: [Preview and Export](/ecodata/xuat-du-lieu/preview-export)

## 6. Run Econometric Analysis and Install AI MCP Skills

- **In the Web Application:** Open the integrated **Econometrics** engine to prepare samples, estimate 105 models across 12 families, cross-validate across Python, R, and Stata 18 MP, and export complete replication code.
- **In AI Assistants and Coding IDEs:** Visit [ecodata.io.vn/account/connect-apps](https://ecodata.io.vn/account/connect-apps) or the [Quick Start MCP Section](https://ecodata.io.vn/quick-start#mcp-integration) to download the five specialized skill files for **Gemini Task / Gemini Gems** `gemini-ecodata-mcp-skill.md`, **AntiGravity** `antigravity-ecodata-skill.md`, **Claude Code** `claude-code-ecodata-skill.md`, **OpenAI Codex** `codex-ecodata-skill.md`, and **Cursor IDE** `cursor-ecodata-rules.mdc`.

→ Details: [Econometrics](/ecodata/cong-cu/econometrics) · Assistant: [AI Chat and MCP](/ecodata/cong-cu/ai-chat)

## Retrieve Data Directly From Excel, Python, Stata, and R

If your research workflow runs in Excel, Python, Stata, or R, use the **EcoData Retrieval Toolkit** powered by the Public SDMX API at `/api/v1/sdmx` with your personal API key.

### 1. Create a Personal API Key

1. Open **Dashboard → API Access**.
2. Create a new key and name it after your project or software client.
3. Copy the full key once and store it securely in an environment variable or `~/.ecodata`.
4. Revoke the key when the project concludes.

### 2. Choose the Standardized Dataflow

| Dataflow | Purpose and Scope |
| --- | --- |
| `MACRO_INTL` | International macro indicators by indicator code, country, and frequency. |
| `GSO_VN` | Vietnam official statistics by indicator, province in 63-province or 34-province mode, dataset, and frequency. |
| `CUSTOMS_VN` | Merchandise trade panels by province, trade flow, measure, and frequency. |
| `STOCK_VN` | Vietnam equity market and corporate financial series by ticker, metric, and frequency. |

### 3. Run the Client in Your Research Software

```python
from ecodata import EcoData

eco = EcoData()
gdp = eco.series(
    "MACRO_INTL",
    indicator="NY.GDP.MKTP.CD",
    ref_area=["VNM", "USA"],
    freq="A",
    start=2010,
)
```

```r
library(ecodata)

gdp <- eco_series(
  "MACRO_INTL",
  indicator = "NY.GDP.MKTP.CD",
  ref_area = c("VNM", "USA"),
  freq = "A",
  start = 2010
)
```

```stata
net install ecodata, from("https://ecodata.io.vn/clients/stata") replace
ecodata setkey eco_live_...
ecodata use MACRO_INTL, indicator(NY.GDP.MKTP.CD) ref_area(VNM USA) freq(A) start(2015) frame(gdp)
```
