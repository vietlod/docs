# Using AI Chat, the 52-Tool Unified EcoData MCP Server, and AI Agent Skills

EcoData provides two complementary pathways for AI-assisted quantitative research: using the built-in **AI Chat** workspace directly in your browser, or connecting the production **Unified EcoData MCP Server** at `https://ecodata.io.vn/mcp` with **52 specialized tools** to external AI assistants and coding IDEs including Gemini Spark, Gemini Gems, AntiGravity, Claude Code, OpenAI Codex, and Cursor IDE.

## Unified 52-Tool MCP Architecture and `server_llm_calls == 0` Execution Lock

The `https://ecodata.io.vn/mcp` gateway unifies EcoData's primary data warehouse and Tri-Engine econometrics runtime with EcoLab's 5-stage scholarly research pipeline through a single connection:

- **37 Native EcoData Data and Econometrics Tools:** Semantic discovery across 200,000+ international macro indicators and seven Vietnam subsystems (`boundary_mode="34"` / `"63"`), 30-year corporate financials across four accounting regimes, VHLSS/PCI/PAPI microdata, and execution across **201+ core estimators in 15 model families** on Python, R, and Stata 18 MP with `.zip` replication bundles.
- **15 Bridged EcoLab 5-Stage Research Tools (`ecolab_*`):** Project and research design bootstrapping (Stage 1), DOI-verified literature synthesis across 6 scholarly databases — OpenAlex, Crossref, DOAJ, arXiv, Semantic Scholar, and CORE (Stage 2), **Zero-Copy** dataset transfer via `ecodata_TransferPayload`, `ecodata_bundle_id`, or `ecodata_csv_url` (Stage 3), dynamic catalog estimation across 201+ models (Stage 4), and 5-gate evidence-locked **Standard IMRaD** or **STORM** manuscript authoring with 300-DPI PNG figures and native Word OMML `.docx` equations (Stage 5).
- **5 Admin Model Curation Tools (`admin_econometrics_*`):** Exposed exclusively to authenticated **Admin** principals to orchestrate Stage A discovery and Stage B 4-gate (`B1–B4`) model verification.
- **Host-LLM Execution Lock (`server_llm_calls == 0`):** Every `/mcp*` call relies strictly on the connected client's Host LLM reasoning (Gemini, Claude, Cursor, Codex), guaranteeing `0` server-side LLM API calls and `0` server AI quota bottlenecks.

## Integrated Workflow Across AI Chat, Dashboard, EcoLab, and Econometrics

1. Submit your research question to **AI Chat** or an AI assistant equipped with a **Unified EcoData MCP Skill** to identify candidate indicators and choose between 34-province and 63-province boundary modes.
2. Inspect metadata definitions, sample coverage, and expand the **Primary Data Source Footnotes** panel in the UI to verify official source tables from the National Statistics Office, Ministry of Finance, and Vietnam Customs.
3. Run pre-estimation diagnostics and execute models from the **201+ estimators across 15 families** directly in the **Econometrics** engine or hand off Zero-Copy into **EcoLab's** 5-stage pipeline.
4. Review outputs audited by the three-tier **Jev Co-Processor** and download the complete `.zip` replication bundle (`Stata 18 MP`, `R`, `Python`, `SHA256SUMS.txt`) alongside publication-ready `.docx` manuscripts.
