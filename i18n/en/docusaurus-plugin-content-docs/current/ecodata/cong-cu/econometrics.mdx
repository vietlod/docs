### How 201+ Estimators Are Parameterized and Fail-Closed Integrity

Each of the **58 mathematical sub-models** pairs its exact structural objective (OLS/HDFE, FGLS, MLE/QMLE, 1-step/2-step Windmeijer GMM, Penalized Splines, Linear Programming DEA, BLP Contraction Mapping) with rigorous variance-covariance structures (Homoskedastic, White Robust HC0–HC3, Newey-West HAC, Driscoll-Kraay, Conley Spatial HAC, One-Way/Multi-Way Clustering, and Wild Cluster Bootstrap).

:::warning[Fail-Closed Methodological Guarantee]
EcoData's Tri-Engine executes the **exact mathematical algorithm** corresponding to every requested estimator key. If an unregistered estimator key is requested or required structural inputs are missing (such as excluded instruments for 2SLS/BLP, spatial weights or coordinates for spatial models, or intermediate proxy inputs for ACF TFP), the engine returns an explicit `422 UNSUPPORTED_ESTIMATOR` or `422 INVALID_SPECIFICATION` error — **never silently falling back to OLS**.
:::

## Estimation Workflow and Three-Language `.zip` Replication Bundles

1. Open the **Econometrics** module in the web workspace or invoke `run_econometrics_model` / `run_complete_econometric_study` via MCP.
2. Execute **Pre-Estimation Diagnostics** on your candidate variables (supporting both `boundary_mode="34"` and `"63"`).
3. Select from the **15 model families** and **201+ core estimators**.
4. Specify dependent, explanatory, endogenous/instrument, entity/time identifiers, and standard-error structures.
5. Run parallel estimation across **Python**, **R**, and **Stata 18 MP** to inspect coefficients, standard errors, $t/z$-statistics, $p$-values, and the full **Postestimation Diagnostics** suite.
6. Switch instantaneously across five publication table standards (**APA 7th**, **Chicago 17th**, **Harvard**, **IEEE**, **MLA 9th**) and export the self-contained **`.zip` Replication Bundle** containing `.do` (Stata 18 MP), `.R`, `.py`, cleaned data slices, and **`SHA256SUMS.txt`** cryptographic checksums.
