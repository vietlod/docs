## 1. Methodological Meaning and Scope of Application

Các giả định và chẩn đoán của hồi quy tuyến tính Mục tiêu học tập Hiểu các giả định của hồi quy OLS Học cách kiểm tra tính phi tuyến, phương sai sai số không đồng nhất, phân phối của các sai số và các giả định khác bằng Stata Hiểu cách xử lý vi phạm các giả định Trong mọi dạng phân tích hồi quy, có một số giả định nhất định phải được đáp ứng. Nếu không, chúng ta không thể tin tưởng rằng các ước lượng từ mô hình của chúng ta là chính xác. Hồi quy bình phương nhỏ nhất là phương pháp ước lượng trung tâm của chúng ta, và khi các giả định của nó được đáp ứng, không có phương pháp nào tốt

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_msehk22u1_c07_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_msehk22u1_c07_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_msehk22u1_c07_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
