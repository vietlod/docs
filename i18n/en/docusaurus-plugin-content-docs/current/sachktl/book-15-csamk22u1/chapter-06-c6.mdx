## 1. Methodological Meaning and Scope of Application

Giới thiệu hồi quy tuyến tính với sai số tương quan An Introduction to Linear Regression with Correlated Errors Tổng quan về chuỗi bài học Chào các bạn sinh viên, chào mừng đến với chuỗi bài học chuyên sâu về một trong những vấn đề phổ biến và quan trọng nhất trong kinh tế lượng ứng dụng: hồi quy tuyến tính với sai số tương quan. Trong các khóa học nhập môn, chúng ta thường bắt đầu với giả định rằng các sai số của mô hình hồi quy là độc lập và có phương sai không đổi. Tuy nhiên, trong thế giới thực, đặc biệt là với dữ liệu kinh tế - xã hội, giả định này hiếm khi được thỏa mãn. Việc bỏ qua sự

- **Supported Analytical Environments**: `Stata 18 MP`.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_csamk22u1_c06_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_csamk22u1_c06_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_csamk22u1_c06_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
