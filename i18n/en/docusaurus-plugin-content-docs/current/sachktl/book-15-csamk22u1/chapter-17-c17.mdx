## 1. Methodological Meaning and Scope of Application

Giới thiệu Mata: Ngôn ngữ lập trình ma trận cho Stata Introduction to Mata: The Matrix Programming Language for Stata Tổng quan về chuỗi bài học Chào các bạn sinh viên, chào mừng đến với chuỗi bài học khám phá Mata, một công cụ cực kỳ mạnh mẽ được tích hợp sẵn trong Stata nhưng không phải ai cũng biết đến và tận dụng. Nếu bạn đã từng cảm thấy các lệnh matrix của Stata có phần hạn chế, hoặc muốn thực hiện các tính toán phức tạp một cách hiệu quả hơn, thì Mata chính là câu trả lời bạn đang tìm kiếm. Mata là một ngôn ngữ lập trình ma trận hoàn chỉnh, có tốc độ xử lý nhanh, cú pháp gần gũi với ký

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_csamk22u1_c17_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_csamk22u1_c17_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_csamk22u1_c17_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
