## 1. Methodological Meaning and Scope of Application

Giới thiệu hồi quy phân vị cho người mới bắt đầu An Introduction to Quantile Regression for Beginners Tổng quan về hồi quy phân vị Chào các bạn sinh viên, trong hành trình khám phá kinh tế lượng, chúng ta thường bắt đầu với mô hình hồi quy tuyến tính cổ điển. OLS là một công cụ cực kỳ mạnh mẽ, giúp chúng ta hiểu được mối quan hệ trung bình giữa các biến. Ví dụ, OLS có thể cho biết trung bình một năm kinh nghiệm làm việc sẽ làm tăng mức lương lên bao nhiêu. Tuy nhiên, thế giới thực lại phức tạp hơn rất nhiều. Liệu tác động của kinh nghiệm lên lương có giống nhau ở nhóm người có thu nhập

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_csamk22u1_c15_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_csamk22u1_c15_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_csamk22u1_c15_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
