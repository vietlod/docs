## 1. Methodological Meaning and Scope of Application

Giới thiệu các phương pháp phi tuyến trong tài chính An Introduction to Nonlinear Methods in Finance Chào mừng các bạn sinh viên đã quay trở lại với series bài học về Kinh tế lượng tài chính! Trong các chương trước, chúng ta đã cùng nhau khám phá thế giới của các mô hình ARMA để phân tích giá trị trung bình và các mô hình GARCH để nắm bắt sự biến động của chuỗi thời gian. Đó là những công cụ cực kỳ mạnh mẽ và là nền tảng không thể thiếu. Tuy nhiên, thế giới tài chính thực tế lại phức tạp hơn nhiều, với những mối quan hệ không phải lúc nào cũng tuân theo quy luật tuyến tính. Các cú sốc bất

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_csipk20u1_c09_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_csipk20u1_c09_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_csipk20u1_c09_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
