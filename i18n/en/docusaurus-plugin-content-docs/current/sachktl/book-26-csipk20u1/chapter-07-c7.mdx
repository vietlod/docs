## 1. Methodological Meaning and Scope of Application

Giới thiệu các phương pháp tự tương quan trong hồi quy Autocorrelation Methods in Regression Models Chào mừng các bạn sinh viên đã đến với chuỗi bài học mới về một chủ đề cực kỳ quan trọng trong kinh tế lượng ứng dụng: các phương pháp xử lý hiện tượng tự tương quan trong mô hình hồi quy. Trong thực tế, khi làm việc với dữ liệu chuỗi thời gian như GDP hàng quý, giá cổ phiếu hàng ngày, hay tỷ lệ lạm phát hàng tháng, chúng ta thường xuyên phải đối mặt với một vấn đề nan giải: các sai số của mô hình không độc lập với nhau. Điều này vi phạm một trong những giả định cốt lõi của phương pháp bình

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_csipk20u1_c07_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_csipk20u1_c07_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_csipk20u1_c07_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
