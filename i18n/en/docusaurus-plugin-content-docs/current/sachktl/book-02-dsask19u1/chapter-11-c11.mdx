## 1. Methodological Meaning and Scope of Application

Chuỗi thời gian không dừng, nghiệm đơn và sự thay đổi cấu trúc Trong phân tích kinh tế lượng chuỗi thời gian, việc xác định tính dừng của dữ liệu là một bước nền tảng và tối quan trọng. Nhiều chuỗi thời gian kinh tế vĩ mô như GDP, tỷ giá hối đoái, hay giá tài sản thường biểu hiện hành vi xu hướng, hay còn gọi là tính không dừng. Sự hiện diện của tính không dừng này, nếu không được xử lý đúng cách, có thể dẫn đến các kết quả hồi quy giả mạo , làm sai lệch hoàn toàn các suy luận thống kê và các khuyến nghị chính sách. ## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_dsask19u1_c11_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_dsask19u1_c11_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_dsask19u1_c11_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
