## 1. Methodological Meaning and Scope of Application

Đồng liên kết và mô hình VAR Trong phân tích chuỗi thời gian, đặc biệt là với dữ liệu kinh tế vĩ mô, các nhà nghiên cứu thường xuyên đối mặt với các biến không dừng. Việc áp dụng mô hình hồi quy OLS truyền thống cho các biến này có thể dẫn đến một cạm bẫy kinh điển được gọi là "hồi quy giả" – nơi các kết quả thống kê có vẻ ý nghĩa nhưng thực chất lại không phản ánh mối quan hệ kinh tế thực sự. Vấn đề này đặt ra một thách thức lớn: làm thế nào để xây dựng mô hình đáng tin cậy cho các biến số kinh tế vốn có xu hướng vận động cùng nhau trong dài hạn, chẳng hạn như tiêu dùng và

- **Core Academic Topics**: Cấu trúc chuỗi bài học, Kiến thức tiên quyết, Mục tiêu học tập, Tài liệu tham khảo chính, PHỤ LỤC: Dữ liệu mô phỏng cho chuỗi bài viết.
- **Supported Analytical Environments**: `Stata 18 MP`.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_dsask19u1_c12_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_dsask19u1_c12_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_dsask19u1_c12_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
