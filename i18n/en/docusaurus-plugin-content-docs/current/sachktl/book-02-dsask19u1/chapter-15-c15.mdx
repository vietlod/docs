## 1. Methodological Meaning and Scope of Application

Phân tích dữ liệu bảng: Mô hình tĩnh Giới thiệu tổng quan về phân tích dữ liệu bảng Trong kinh tế lượng, chúng ta thường làm việc với hai loại dữ liệu chính: dữ liệu chéo và dữ liệu chuỗi thời gian . Tuy nhiên, sức mạnh thực sự được khai mở khi chúng ta kết hợp cả hai chiều này lại với nhau, tạo thành dữ liệu bảng. Dữ liệu bảng, hay còn gọi là dữ liệu dọc, theo dõi một nhóm các cá nhân, công ty, hoặc quốc gia qua nhiều giai đoạn thời gian, cung cấp một cái nhìn đa chiều và sâu sắc hơn về các mối quan hệ kinh tế. Ưu điểm vượt trội của dữ liệu bảng nằm ở khả năng giải quyết một

- **Core Academic Topics**: Giới thiệu tổng quan về phân tích dữ liệu bảng, Cấu trúc chuỗi bài học, Kiến thức tiên quyết, Mục tiêu học tập, Tài liệu tham khảo chính.
- **Supported Analytical Environments**: `Stata 18 MP`.
- **Recommended Empirical Data Sources**: Vietnamese macroeconomic, corporate, and household survey datasets on [EcoData](https://ecodata.io.vn), capital and commodity market series on [Finco](https://www.finco.vn), model cross-references on [VietLOD](https://vietlod.tnsai.vn), and automated estimation on [EcoLab](https://ecolab.io.vn).

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_dsask19u1_c15_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_dsask19u1_c15_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_dsask19u1_c15_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
