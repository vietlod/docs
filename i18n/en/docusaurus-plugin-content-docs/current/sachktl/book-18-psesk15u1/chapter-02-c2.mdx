## 1. Methodological Meaning and Scope of Application

Giới thiệu hồi quy bội cho người mới bắt đầu An Introduction to Multiple Regression for Beginners Tổng quan về hồi quy bội Chào mừng các bạn sinh viên đã quay trở lại với chuỗi bài học về kinh tế lượng! Ở các học phần trước, chúng ta đã làm quen với hồi quy tuyến tính đơn, một công cụ mạnh mẽ để phân tích mối quan hệ giữa hai biến số. Tuy nhiên, thế giới kinh tế trong thực tế lại phức tạp hơn nhiều. Các hiện tượng kinh tế như tăng trưởng GDP, lạm phát, hay giá nhà đất không chỉ bị ảnh hưởng bởi một yếu tố duy nhất, mà là kết quả của sự tương tác giữa nhiều yếu tố khác nhau. Đây chính là lúc

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_psesk15u1_c02_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_psesk15u1_c02_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_psesk15u1_c02_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
