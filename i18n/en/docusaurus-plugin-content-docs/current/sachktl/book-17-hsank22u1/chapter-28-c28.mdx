## 1. Methodological Meaning and Scope of Application

Lựa chọn mô hình, co Stein và trung bình hóa mô hình Chào mừng các bạn sinh viên đến với chuỗi bài học chuyên sâu về một trong những kỹ năng quan trọng nhất của nhà kinh tế lượng thực hành: làm thế nào để lựa chọn một mô hình tốt nhất từ vô số các khả năng. Trong quá trình học tập và nghiên cứu, chắc hẳn các bạn đã từng băn khoăn khi phải quyết định nên đưa biến nào vào mô hình hồi quy, hay nên sử dụng dạng hàm nào là phù hợp. Chuỗi bài học này sẽ trang bị cho các bạn những công cụ lý thuyết vững chắc và kỹ năng thực hành cần thiết để trả lời những câu hỏi đó một cách khoa học và có hệ thống.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_hsank22u1_c28_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_hsank22u1_c28_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_hsank22u1_c28_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
