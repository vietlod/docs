## 1. Methodological Meaning and Scope of Application

Lựa chọn đa cấp Giới thiệu chuỗi bài học về các mô hình lựa chọn đa danh mục Chào các bạn sinh viên, chào mừng đến với một trong những chủ đề thú vị và có tính ứng dụng cao nhất trong kinh tế lượng: các mô hình lựa chọn đa danh mục. Trong cuộc sống hàng ngày, chúng ta liên tục phải đưa ra những lựa chọn giữa nhiều hơn hai phương án: chọn trường đại học nào, mua chiếc xe hiệu gì, sử dụng phương tiện nào để đi làm, hay đơn giản là chọn món ăn nào cho bữa trưa. Các mô hình mà chúng ta sắp tìm hiểu sẽ cung cấp một bộ công cụ mạnh mẽ để phân tích và dự báo những hành vi lựa chọn phức tạp này.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_hsank22u1_c26_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_hsank22u1_c26_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_hsank22u1_c26_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
