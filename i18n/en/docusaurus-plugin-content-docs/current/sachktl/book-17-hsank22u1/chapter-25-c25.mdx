## 1. Methodological Meaning and Scope of Application

Lựa chọn nhị phân Chào mừng các bạn sinh viên đến với chuỗi bài học về Mô hình Lựa chọn Nhị phân . Trong kinh tế và cuộc sống, chúng ta thường xuyên đối mặt với những quyết định chỉ có hai kết quả: một sinh viên quyết định học cao học hay đi làm, một người tiêu dùng chọn mua hay không mua một sản phẩm, một ngân hàng phê duyệt hay từ chối một khoản vay. Các mô hình lựa chọn nhị phân chính là công cụ kinh tế lượng mạnh mẽ giúp chúng ta phân tích và dự báo xác suất xảy ra của những sự kiện "có/không" này. Chuỗi bài học này được thiết kế đặc biệt để dẫn dắt các bạn đi từ những khái niệm cơ bản

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_hsank22u1_c25_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_hsank22u1_c25_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_hsank22u1_c25_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
