## 1. Methodological Meaning and Scope of Application

Chuỗi thời gian đa biến Chào mừng các bạn sinh viên đến với một trong những công cụ mạnh mẽ và được sử dụng rộng rãi nhất trong kinh tế lượng hiện đại: mô hình chuỗi thời gian đa biến. Trong thực tế, các biến kinh tế hiếm khi vận động một cách độc lập. Lãi suất ảnh hưởng đến lạm phát, lạm phát tác động đến tăng trưởng GDP, và tăng trưởng GDP lại ảnh hưởng ngược lại đến các quyết định chính sách. Để nắm bắt được những mối quan hệ tương tác phức tạp này, chúng ta cần một công cụ có thể phân tích đồng thời nhiều chuỗi thời gian, và đó chính là lúc mô hình Tự Hồi quy Vector, hay còn gọi là mô

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_hsank22u1_c15_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_hsank22u1_c15_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_hsank22u1_c15_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
