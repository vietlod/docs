## 1. Methodological Meaning and Scope of Application

Hồi quy chuỗi Chào mừng các bạn sinh viên đến với chuỗi bài học mới về một công cụ cực kỳ mạnh mẽ trong kinh tế lượng: Hồi quy chuỗi . Trong các môn học nhập môn, chúng ta thường bắt đầu với mô hình hồi quy tuyến tính OLS. Tuy nhiên, thực tế kinh tế hiếm khi tuân theo một đường thẳng hoàn hảo. Mối quan hệ giữa giáo dục và thu nhập, hay giữa kinh nghiệm và năng suất, thường có dạng cong hoặc phức tạp hơn nhiều. Vậy làm thế nào để mô hình hóa những mối quan hệ phi tuyến tính này một cách linh hoạt mà không cần phải "đoán" trước hình dạng của chúng? Hồi quy chuỗi chính là câu trả lời. Ý tưởng

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_hsank22u1_c20_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_hsank22u1_c20_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_hsank22u1_c20_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
