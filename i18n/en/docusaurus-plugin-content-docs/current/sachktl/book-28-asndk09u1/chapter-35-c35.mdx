## 1. Methodological Meaning and Scope of Application

Giới thiệu về mô hình hóa rủi ro tín dụng An Introduction to Credit Risk Modeling Tổng quan về chuỗi bài học Chào mừng các bạn sinh viên đến với chuỗi bài học chuyên sâu về Mô hình hóa Rủi ro Tín dụng. Trong bối cảnh kinh tế toàn cầu đầy biến động, rủi ro tín dụng - tức khả năng một bên đi vay không thể thực hiện nghĩa vụ trả nợ - đã trở thành một trong những mối quan tâm hàng đầu của các ngân hàng, tổ chức tài chính và nhà đầu tư. Việc hiểu và đo lường chính xác rủi ro này không chỉ giúp bảo vệ danh mục cho vay mà còn là nền tảng để định giá các công cụ tài chính phức tạp và đưa ra các quyết

- **Core Academic Topics**: Tổng quan về chuỗi bài học, CẤU TRÚC CHUỖI BÀI HỌC, KIẾN THỨC TIÊN QUYẾT, MỤC TIÊU HỌC TẬP, TÀI LIỆU THAM KHẢO.
- **Supported Analytical Environments**: `Stata 18 MP`.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_asndk09u1_c35_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_asndk09u1_c35_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_asndk09u1_c35_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
