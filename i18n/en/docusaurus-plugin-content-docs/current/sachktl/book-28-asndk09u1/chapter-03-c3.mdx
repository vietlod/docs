## 1. Methodological Meaning and Scope of Application

Giới thiệu mô hình ARCH và trí nhớ dài An Introduction to ARCH models and Long Memory TÓM TẮT CHỦ ĐỀ Chào các bạn sinh viên, chào mừng đến với chuỗi bài học khám phá một trong những chủ đề hấp dẫn và hiện đại nhất của kinh tế lượng tài chính: Mô hình ARCH và Tính chất Trí nhớ Dài. Nếu các bạn đã quen thuộc với các mô hình GARCH dùng để dự báo biến động, thì ARCH chính là một sự tổng quát hóa mạnh mẽ và linh hoạt hơn rất nhiều. Thay vì bị giới hạn bởi một vài độ trễ, mô hình này cho phép biến động hiện tại bị ảnh hưởng bởi toàn bộ lịch sử của chuỗi dữ liệu, kéo dài đến vô tận. Điểm

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_asndk09u1_c03_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_asndk09u1_c03_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_asndk09u1_c03_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
