## 1. Methodological Meaning and Scope of Application

Giới thiệu Mô hình Biến phụ thuộc Giới hạn và Điều chỉnh Chọn mẫu Chào mừng các bạn sinh viên đã đến với chuỗi bài học chuyên sâu về một trong những lĩnh vực hấp dẫn và thực tiễn nhất của kinh tế lượng ứng dụng: các mô hình dành cho Biến phụ thuộc Giới hạn, hay còn gọi là Limited Dependent Variable models. Trong thực tế, rất nhiều biến số kinh tế mà chúng ta quan tâm không thể nhận bất kỳ giá trị nào một cách tự do. Chẳng hạn, một người quyết định có đi làm hay không , số giờ làm việc , hay số bằng sáng chế một công ty đăng ký . Những biến số bị "giới hạn" như vậy đòi hỏi chúng ta phải

  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_wsook19u1_c17_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_wsook19u1_c17_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
