## 1. Methodological Meaning and Scope of Application

Mô hình đa biến Giới thiệu chuỗi bài học Chào mừng các bạn sinh viên đã quay trở lại với hành trình khám phá kinh tế lượng! Trong các chương trước, chúng ta đã cùng nhau làm chủ các mô hình hồi quy đơn phương trình, nơi một biến phụ thuộc được giải thích bởi một hoặc nhiều biến độc lập. Cách tiếp cận này rất mạnh mẽ, nhưng nó dựa trên một giả định quan trọng: mối quan hệ nhân quả chỉ đi theo một chiều. Tuy nhiên, trong thế giới kinh tế và tài chính thực tế, các mối quan hệ thường phức tạp hơn nhiều. Giá cả ảnh hưởng đến lượng cầu, nhưng đồng thời lượng cầu cũng tác động ngược trở lại giá cả.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_bsrok19u1_c07_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_bsrok19u1_c07_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_bsrok19u1_c07_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
