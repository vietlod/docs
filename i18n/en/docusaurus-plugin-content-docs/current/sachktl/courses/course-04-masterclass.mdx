## Six Bundled Learning Resources Attached to Every Lecture

1. **Standardized Practice Dataset `.csv`:** Empirical Vietnamese macroeconomic and corporate data from [EcoData](https://ecodata.io.vn) and [Finco](https://www.finco.vn).
2. **Stata 18 MP Script `.do`:** Complete script covering data import, estimation, robust standard errors, and post-estimation diagnostics.
3. **R 4.x Script `.R`:** Full R replication script producing identical parameter estimates and diagnostic test statistics.
4. **Python 3.11+ Script `.py`:** Modern Python quantitative script powered by `statsmodels`, `linearmodels`, and `scipy`.
5. **Three-Software Convergence Plot `.png`:** High-resolution visual proof of estimation convergence across Stata, R, and Python.
6. **Lecture Summary Handout `.md`:** Concise reference sheet with structural equations, identification conditions, and APA 7th parameter tables.
