## 1. Methodological Meaning and Scope of Application

Tổng quan về mô hình hóa phương trình cấu trúc Framing Structural Equation Modelling Giới thiệu về chuỗi bài học mô hình phương trình cấu trúc Chào mừng các bạn đến với chuỗi bài học nhập môn về Mô hình hóa Phương trình Cấu trúc, thường được biết đến với tên viết tắt là SEM. Trong thế giới nghiên cứu kinh tế và xã hội, chúng ta thường phải đối mặt với những câu hỏi phức tạp hơn là chỉ xem xét mối quan hệ một chiều giữa hai biến. Ví dụ, sự hài lòng của sinh viên không chỉ ảnh hưởng đến lòng trung thành với nhà trường, mà bản thân sự hài lòng lại được hình thành từ nhiều yếu tố khác như chất

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_msehk21u1_c01_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_msehk21u1_c01_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_msehk21u1_c01_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
