## 1. Methodological Meaning and Scope of Application

Chọn mẫu: mô hình hóa thu nhập khi nghề nghiệp được lựa chọn Chào mừng các bạn sinh viên đến với chuỗi bài học chuyên sâu về một trong những vấn đề kinh tế lượng phổ biến và quan trọng nhất trong phân tích dữ liệu vi mô: sai lệch chọn mẫu . Trong thực tế, hiếm khi chúng ta có được một mẫu dữ liệu hoàn toàn ngẫu nhiên. Ví dụ, khi nghiên cứu về các yếu tố ảnh hưởng đến tiền lương, chúng ta chỉ có thể thu thập dữ liệu từ những người có việc làm. Vậy những người không có việc làm thì sao? ## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_fsrak15u1_c22_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_fsrak15u1_c22_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_fsrak15u1_c22_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
