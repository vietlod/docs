## 1. Methodological Meaning and Scope of Application

Phụ thuộc chéo và dữ liệu không dừng Chào mừng các bạn sinh viên đã quay trở lại với series kinh tế lượng ứng dụng! Trong các bài học trước, chúng ta đã làm quen với dữ liệu bảng, nhưng chủ yếu tập trung vào trường hợp có số lượng cá nhân lớn và số quan sát thời gian nhỏ. Tuy nhiên, trong kinh tế học phát triển và kinh tế vĩ mô, chúng ta thường xuyên gặp phải những bộ dữ liệu bảng "dài", nơi chiều thời gian đủ lớn để các vấn đề phức tạp hơn phát sinh. Chương này sẽ là một hành trình khám phá ba thách thức lớn nhưng cũng vô cùng thú vị khi làm việc với loại dữ liệu này. Hãy tưởng tượng

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_fsrak15u1_c28_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_fsrak15u1_c28_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_fsrak15u1_c28_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
