## 1. Methodological Meaning and Scope of Application

Mô hình hóa tác động của viện trợ và các yếu tố quyết định tăng trưởng Chào mừng các bạn sinh viên đến với một trong những cuộc tranh luận hấp dẫn và gai góc nhất trong kinh tế học phát triển: Liệu viện trợ nước ngoài có thực sự thúc đẩy tăng trưởng kinh tế không? Tại sao có những nghiên cứu uy tín lại kết luận rằng viện trợ là động lực cho sự phát triển, trong khi những nghiên cứu khác, sử dụng dữ liệu tương tự, lại cho rằng nó không có tác dụng, thậm chí là tiêu cực? Đây không chỉ là một câu hỏi lý thuyết, mà còn ảnh hưởng đến quyết định phân bổ hàng tỷ đô la mỗi năm trên toàn thế giới.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_fsrak15u1_c26_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_fsrak15u1_c26_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_fsrak15u1_c26_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
