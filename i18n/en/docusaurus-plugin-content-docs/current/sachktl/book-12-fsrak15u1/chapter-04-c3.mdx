## 1. Methodological Meaning and Scope of Application

Mở rộng mô hình hồi quy đơn Chào mừng các bạn sinh viên đã quay trở lại với chuỗi bài học về kinh tế lượng ứng dụng! Ở chương trước, chúng ta đã làm quen với một công cụ rất mạnh mẽ là mô hình hồi quy tuyến tính đơn, giúp ước lượng tác động của một biến lên một kết quả mà chúng ta quan tâm. Tuy nhiên, thực tế luôn phức tạp hơn thế. Liệu chỉ có giáo dục mới quyết định thu nhập? Hay còn các yếu tố khác như kinh nghiệm, kỹ năng bẩm sinh, hay thậm chí là may mắn? Mô hình hồi quy đơn, dù hữu ích, lại có một hạn chế lớn: nó gom tất cả các yếu tố không được giải thích

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_fsrak15u1_c04_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_fsrak15u1_c04_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_fsrak15u1_c04_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
