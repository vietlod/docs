## 1. Methodological Meaning and Scope of Application

Kiểm định giả thuyết Chào mừng các bạn sinh viên đã quay trở lại với chuỗi bài học về kinh tế lượng! Ở các chương trước, chúng ta đã học cách sử dụng phương pháp Bình phương Tối thiểu Thông thường để tìm ra các hệ số ước lượng cho mô hình của mình. Tuy nhiên, việc ước lượng chỉ là bước khởi đầu. Một câu hỏi quan trọng hơn luôn cần được trả lời là: Liệu những con số chúng ta tìm được có thực sự ý nghĩa về mặt thống kê, hay chúng chỉ là kết quả của sự ngẫu nhiên trong mẫu dữ liệu? Làm thế nào để chúng ta có thể tự tin kết luận rằng một biến độc lập thực sự có tác động lên biến phụ thuộc?

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_fsrak15u1_c05_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_fsrak15u1_c05_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_fsrak15u1_c05_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
