## 1. Methodological Meaning and Scope of Application

Dữ liệu bảng: giới thiệu Chào mừng các bạn sinh viên đến với chuỗi bài học về một trong những công cụ mạnh mẽ nhất của kinh tế lượng hiện đại: Dữ liệu Bảng. Nếu các bạn đã từng băn khoăn về việc làm thế nào để chứng minh một mối quan hệ nhân quả, hay luôn đối mặt với câu hỏi "liệu có một yếu tố nào đó mà chúng ta không đo lường được đang ảnh hưởng đến kết quả không?", thì chuỗi bài học này chính là câu trả lời mà các bạn đang tìm kiếm. ## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_fsrak15u1_c10_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_fsrak15u1_c10_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_fsrak15u1_c10_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
