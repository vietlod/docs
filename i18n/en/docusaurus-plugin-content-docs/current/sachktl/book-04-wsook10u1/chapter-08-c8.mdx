## 1. Methodological Meaning and Scope of Application

Giới thiệu Ước lượng Hệ thống bằng Biến công cụ Chào mừng các bạn sinh viên đã quay trở lại với chuỗi bài học kinh tế lượng ứng dụng! Trong các chương trước, chúng ta đã làm quen với các công cụ mạnh mẽ để phân tích mối quan hệ kinh tế, từ hồi quy OLS, các mô hình SUR cho đến phương pháp biến công cụ cho một phương trình đơn lẻ. Tuy nhiên, thế giới kinh tế thực tế hiếm khi vận hành qua những phương trình riêng lẻ. Các biến số thường tác động qua lại lẫn nhau trong một hệ thống phức tạp, ví dụ như giá cả và sản lượng được quyết định đồng thời bởi cung và cầu. Khi đó, việc chỉ sử

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_wsook10u1_c08_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_wsook10u1_c08_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_wsook10u1_c08_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
