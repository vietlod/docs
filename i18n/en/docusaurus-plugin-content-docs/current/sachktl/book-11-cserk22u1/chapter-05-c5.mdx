## 1. Methodological Meaning and Scope of Application

Phương pháp sai biệt kép với nhiều thời điểm trước và sau can thiệp Chào mừng các bạn sinh viên đến với chuỗi bài học chuyên sâu về một trong những phương pháp quan trọng nhất trong kinh tế lượng ứng dụng: Sai biệt kép, hay còn gọi là Difference-in-Differences. Trong các học phần nhập môn, chúng ta thường làm quen với mô hình DID cơ bản chỉ với hai nhóm và hai thời điểm . Tuy nhiên, thực tế nghiên cứu thường phức tạp hơn rất nhiều, với dữ liệu kéo dài qua nhiều năm và các chính sách được áp dụng không đồng đều. ## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_cserk22u1_c05_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cserk22u1_c05_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cserk22u1_c05_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
