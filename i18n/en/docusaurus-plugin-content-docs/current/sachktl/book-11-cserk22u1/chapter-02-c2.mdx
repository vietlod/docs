## 1. Methodological Meaning and Scope of Application

Các phương pháp dựa trên lựa chọn các biến quan sát được Chào mừng các bạn sinh viên đến với chuỗi bài học về các phương pháp đánh giá tác động trong kinh tế lượng. Trong thế giới thực, chúng ta hiếm khi có được dữ liệu từ các thí nghiệm ngẫu nhiên có kiểm soát hoàn hảo. Thay vào đó, chúng ta thường phải làm việc với dữ liệu quan sát, nơi các cá nhân, doanh nghiệp, hay chính phủ tự lựa chọn tham gia vào một chương trình, chính sách nào đó. Điều này tạo ra một thách thức lớn gọi là "thiên kiến lựa chọn", khiến việc so sánh đơn giản giữa nhóm tham gia và không tham gia trở nên

- **Core Academic Topics**: Cấu trúc chuỗi bài học, PHỤ LỤC: Dữ liệu mô phỏng cho chuỗi bài viết.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_cserk22u1_c02_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cserk22u1_c02_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cserk22u1_c02_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
