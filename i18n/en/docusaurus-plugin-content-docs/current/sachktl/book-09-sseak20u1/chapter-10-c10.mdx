## 1. Methodological Meaning and Scope of Application

Giới thiệu chuỗi bài học về mô hình chuỗi thời gian không dừng An Introduction to Nonstationary Time Series models Chào mừng các nhà kinh tế lượng tương lai Chào mừng các bạn sinh viên đã đến với một trong những chủ đề hấp dẫn và thực tiễn nhất trong kinh tế lượng: phân tích chuỗi thời gian không dừng. Nếu các bạn từng nhìn vào biểu đồ GDP, giá cổ phiếu, hay dân số và thấy chúng có xu hướng tăng mãi theo thời gian, thì các bạn đã bắt gặp chuỗi không dừng rồi đấy. Dữ liệu kinh tế trong thực tế hiếm khi "đứng yên", chúng luôn vận động, tăng trưởng, và thay đổi. Việc phân tích các chuỗi dữ liệu

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_sseak20u1_c10_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_sseak20u1_c10_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_sseak20u1_c10_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
