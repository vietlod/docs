## 1. Methodological Meaning and Scope of Application

Giới thiệu về thí nghiệm và tựa thí nghiệm An Introduction to Experiments and Quasi-experiments Giới thiệu tổng quan Chào các bạn sinh viên, trong hành trình khám phá kinh tế lượng, một trong những câu hỏi quan trọng và thách thức nhất mà chúng ta luôn phải đối mặt là: "Làm thế nào để xác định được tác động nhân quả thực sự của một chính sách hay một sự kiện?" Ví dụ, một chương trình đào tạo việc làm có thực sự giúp tăng thu nhập của người lao động không? Hay việc giảm quy mô lớp học có thực sự cải thiện kết quả học tập của học sinh? Trả lời những câu hỏi này một cách đáng tin cậy đòi hỏi

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_sstok20u1_c13_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_sstok20u1_c13_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_sstok20u1_c13_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
