## 1. Methodological Meaning and Scope of Application

Giới thiệu về câu hỏi kinh tế và dữ liệu Introduction to Economic Questions and Data Tổng quan chuỗi bài học Chào mừng các bạn sinh viên đến với chuỗi bài học nhập môn về Kinh tế lượng! Nếu bạn từng thắc mắc làm thế nào các nhà kinh tế có thể đưa ra những con số cụ thể như "giảm quy mô lớp học giúp tăng 5% điểm thi" hay "tăng thuế thuốc lá 10% sẽ giảm 4% lượng tiêu thụ", thì chuỗi bài học này chính là câu trả lời. ## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_sstok20u1_c01_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_sstok20u1_c01_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_sstok20u1_c01_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
