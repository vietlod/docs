## 1. Methodological Meaning and Scope of Application

Giới thiệu về ước lượng hiệu ứng nhân quả động An Introduction to Estimating Dynamic Causal Effects Chào các bạn sinh viên, chào mừng các bạn đến với chuỗi bài học mới đầy thú vị trong lĩnh vực kinh tế lượng chuỗi thời gian. Trong thực tế, các chính sách kinh tế hay sự kiện thị trường không chỉ có tác động tức thời mà còn kéo dài theo thời gian. Ví dụ, một quyết định tăng lãi suất của ngân hàng trung ương hôm nay có thể ảnh hưởng đến lạm phát và tăng trưởng kinh tế trong nhiều quý tới. Việc đo lường và hiểu rõ con đường tác động này chính là nhiệm vụ của việc ước lượng hiệu ứng nhân quả động.

- **Core Academic Topics**: CẤU TRÚC CHUỖI BÀI HỌC, KIẾN THỨC TIÊN QUYẾT, MỤC TIÊU HỌC TẬP, TÀI LIỆU THAM KHẢO, PHỤ LỤC: Dữ liệu mô phỏng cho series.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_sstok20u1_c16_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_sstok20u1_c16_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_sstok20u1_c16_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
