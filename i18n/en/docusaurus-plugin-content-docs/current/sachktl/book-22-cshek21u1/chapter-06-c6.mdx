## 1. Methodological Meaning and Scope of Application

Đo lường tính không đồng nhất trong Phân tích tổng hợp Heterogeneity in Meta-Analysis Tóm tắt nội dung chuỗi bài viết Chào mừng các bạn đến với chuỗi bài học chuyên sâu về một trong những khái niệm quan trọng và tinh tế nhất trong phân tích tổng hợp: tính không đồng nhất. Ở chuỗi bài trước, chúng ta đã học cách kết hợp kết quả từ nhiều nghiên cứu để đưa ra một ước lượng tổng thể về hiệu ứng can thiệp. Tuy nhiên, một câu hỏi quan trọng luôn được đặt ra: Liệu hiệu ứng can thiệp đó có thực sự giống nhau ở tất cả các nghiên cứu hay không? Hay nó thay đổi tùy thuộc vào đặc điểm của người tham gia,

- **Supported Analytical Environments**: `Stata 18 MP`.

## 3. Multi-Platform Implementation Examples in Stata, R, and Python

<Tabs>
  <TabItem value="stata" label="Stata 18 MP" default>

```stata
* Initialize environment and load practice dataset from EcoData / SachKTL
version 18.0
clear all
set more off

* Import standardized empirical dataset
import delimited "sachktl_cshek21u1_c06_ecodata.csv", clear encoding("utf-8")
describe
summarize

* Estimate baseline specification and run diagnostic checks with robust standard errors
regress y x1 x2 x3, vce(robust)
estat hettest
estat vif
```

  </TabItem>
  <TabItem value="r" label="R 4.x">

```r
# Load econometric packages and practice dataset from EcoData / SachKTL
library(tidyverse)
library(lmtest)
library(sandwich)

df <- read.csv("sachktl_cshek21u1_c06_ecodata.csv")
summary(df)

# Estimate model and compute heteroskedasticity-robust HC1 standard errors
fit <- lm(y ~ x1 + x2 + x3, data = df)
coeftest(fit, vcov = vcovHC(fit, type = "HC1"))
```

  </TabItem>
  <TabItem value="python" label="Python 3.11+">

```python
# Load econometric libraries and practice dataset from EcoData / SachKTL
import pandas as pd
import statsmodels.formula.api as smf

df = pd.read_csv("sachktl_cshek21u1_c06_ecodata.csv")
print(df.describe())

# Fit specification with HC1 robust standard errors
model = smf.ols("y ~ x1 + x2 + x3", data=df).fit(cov_type="HC1")
print(model.summary())
```
