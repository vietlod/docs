## 6.1.1.1. Methodological Meaning and Scope of Application

### 6.1.1.1.1. Econometric Foundation and Identification Mechanism

Estimates the Augmented Dickey-Fuller Unit Root Regression specification within the Unit Root and Cointegration Tests framework by optimizing the structural objective function and computing heteroskedasticity- and cluster-robust asymptotic standard errors. Across empirical econometrics, `adf` enables researchers to isolate structural parameters while controlling for confounding covariates and verifying identification assumptions via `base Stata` in Stata 18 MP, `tseries / urca` in R 4.x, and `statsmodels` in Python 3.11+.

### 6.1.1.1.2. Scope of Application and Sample Structure Requirements

Chronologically ordered macro-financial time series requiring stationarity, lag-order selection, and serial-correlation diagnostics. Mandatory post-estimation verification includes testing identification restrictions, evaluating goodness-of-fit metrics, and confirming numerical convergence across all three econometric engines.

### 6.1.1.1.3. Structural Equations and Asymptotic Covariance Specification

Core structural equation for `adf`:

$$
\Delta Y_t = \alpha + \beta t + \gamma Y_{t-1} + \sum_{j=1}^p \delta_j \Delta Y_{t-j} + \varepsilon_t
$$

Estimator objective function and sample moment conditions:

$$
\hat{\theta}_T = \arg\max_{\theta \in \Theta} \ell_T\left(Y_1, \dots, Y_T; \theta\right), \quad \Phi(L)(1-L)^d Y_t = \mu + \Theta(L)\varepsilon_t
$$

Asymptotic covariance matrix and post-estimation diagnostic metric:

$$
\text{AICc} = -2\ell_T(\hat{\theta}) + 2k + \frac{2k(k+1)}{T-k-1}, \quad Q_{\text{LB}}(m) = T(T+2)\sum_{\ell=1}^m \frac{\hat{\rho}_\ell^2}{T-\ell} \xrightarrow{d} \chi^2_{m-p-q}
$$

# ==============================================================================
# MODEL 6.1.1 — CODE B084: AUGMENTED DICKEY-FULLER UNIT ROOT REGRESSION
# Runtime: R 4.x | Primary Package: tseries / urca
# Practice Dataset: vietlod_adf_ecodata.csv | Sample Size N = 320

  library(stats)
  library(sandwich)
  library(lmtest)

summary(df[, c("y", "x1", "x2")])

# 2. Estimate model and compute HC1 robust covariance matrix
fit_adf <- lm(y ~ x1 + x2, data = df)
coeftest(fit_adf, vcov = vcovHC(fit_adf, type = "HC1"))
# Specialized tseries / urca syntax: urca::ur.df[df$y, type = 'trend', lags = 2]
