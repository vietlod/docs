## 6.3.1.1. Methodological Meaning and Scope of Application

### 6.3.1.1.1. Econometric Foundation and Identification Mechanism

Estimates the Autoregressive Distributed Lag — ARDL specification within the Autoregressive Distributed Lag Models framework by optimizing the structural objective function and computing heteroskedasticity- and cluster-robust asymptotic standard errors. Across empirical econometrics, `ardl` enables researchers to isolate structural parameters while controlling for confounding covariates and verifying identification assumptions via `Stata ardl` in Stata 18 MP, `ARDL / dynlm` in R 4.x, and `statsmodels` in Python 3.11+.

### 6.3.1.1.2. Scope of Application and Sample Structure Requirements

Chronologically ordered macro-financial time series requiring stationarity, lag-order selection, and serial-correlation diagnostics. Mandatory post-estimation verification includes testing identification restrictions, evaluating goodness-of-fit metrics, and confirming numerical convergence across all three econometric engines.

### 6.3.1.1.3. Structural Equations and Asymptotic Covariance Specification

Core structural equation for `ardl`:

$$
Y_t = c + \sum_{i=1}^p \phi_i Y_{t-i} + \sum_{k=1}^K \sum_{j=0}^{q_k} \beta_{k,j} X_{k,t-j} + \varepsilon_t
$$

Estimator objective function and sample moment conditions:

$$
\hat{\theta}_T = \arg\max_{\theta \in \Theta} \ell_T\left(Y_1, \dots, Y_T; \theta\right), \quad \Phi(L)(1-L)^d Y_t = \mu + \Theta(L)\varepsilon_t
$$

Asymptotic covariance matrix and post-estimation diagnostic metric:

$$
\text{AICc} = -2\ell_T(\hat{\theta}) + 2k + \frac{2k(k+1)}{T-k-1}, \quad Q_{\text{LB}}(m) = T(T+2)\sum_{\ell=1}^m \frac{\hat{\rho}_\ell^2}{T-\ell} \xrightarrow{d} \chi^2_{m-p-q}
$$

# ==============================================================================
# MODEL 6.3.1 — CODE B095: AUTOREGRESSIVE DISTRIBUTED LAG — ARDL

  library(stats)
  library(sandwich)

# 2. Estimate model and compute HC1 robust covariance matrix
fit_ardl <- lm(y ~ x1 + x2, data = df)
coeftest(fit_ardl, vcov = vcovHC(fit_ardl, type = "HC1"))
# Specialized ARDL / dynlm syntax: ARDL::ardl[y ~ x1 + x2, data = df, order = c[2, 1, 1]]
