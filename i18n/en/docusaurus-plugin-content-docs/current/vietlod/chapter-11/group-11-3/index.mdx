- **Methodological Focus**: Provides consistent estimation and robust inference for **Parametric Accelerated Failure Time Models** specifications within **Survival, Event History and Competing-Risks Analysis**.

Core structural specification for Group 11.3:

$$
\ln(T_i) = X_i^\top \beta + \sigma \varepsilon_i, \quad f(\varepsilon) = \exp(\varepsilon - e^\varepsilon)
$$

$$
\ell_{\text{partial}}(\beta) = \sum_{i=1}^N \delta_i \left[X_i^\top \beta - \ln\left(\sum_{j \in \mathcal{R}(t_i)} \exp(X_j^\top \beta)\right)\right], \quad S(t \mid X_i) = \exp\left(-H_0(t)\exp(X_i^\top \beta)\right)
$$
