## 7.1.1.1. Methodological Meaning and Scope of Application

### 7.1.1.1.1. Econometric Foundation and Identification Mechanism

Estimates the Vector Autoregression — VAR specification within the Vector Autoregression, VECM and Structural VAR framework by optimizing the structural objective function and computing heteroskedasticity- and cluster-robust asymptotic standard errors. Across empirical econometrics, `var` enables researchers to isolate structural parameters while controlling for confounding covariates and verifying identification assumptions via `base Stata` in Stata 18 MP, `vars` in R 4.x, and `statsmodels` in Python 3.11+.

### 7.1.1.1.2. Scope of Application and Sample Structure Requirements

Chronologically ordered macro-financial time series requiring stationarity, lag-order selection, and serial-correlation diagnostics. Mandatory post-estimation verification includes testing identification restrictions, evaluating goodness-of-fit metrics, and confirming numerical convergence across all three econometric engines.

### 7.1.1.1.3. Structural Equations and Asymptotic Covariance Specification

Core structural equation for `var`:

$$
Y_t = c + A_1 Y_{t-1} + \dots + A_p Y_{t-p} + u_t, \quad \text{E}[u_t u_t^\top] = \Sigma_u
$$

Estimator objective function and sample moment conditions:

$$
Y_t = c + \sum_{\ell=1}^p A_\ell Y_{t-\ell} + B^{-1}\Sigma_u \varepsilon_t, \quad \Psi_h = \frac{\partial Y_{t+h}}{\partial \varepsilon_t^\top} = \Phi_h B^{-1}\Sigma_u
$$

Asymptotic covariance matrix and post-estimation diagnostic metric:

$$
\text{FEVD}_{j \leftarrow k}(H) = \frac{\sum_{h=0}^{H-1}\left(e_j^\top \Psi_h e_k\right)^2}{\sum_{h=0}^{H-1} e_j^\top \Psi_h \Psi_h^\top e_j}, \quad \det\left(I_K - \sum_{\ell=1}^p A_\ell z^\ell\right) \neq 0 \;\forall |z| \le 1
$$

  library(stats)
  library(sandwich)

# 2. Estimate model and compute HC1 robust covariance matrix
fit_var <- lm(y ~ x1 + x2, data = df)
coeftest(fit_var, vcov = vcovHC(fit_var, type = "HC1"))
