## 5.1.10.1. Methodological Meaning and Scope of Application

### 5.1.10.1.1. Econometric Foundation and Identification Mechanism

Estimates fixed-effects panel parameters with pairwise cross-sectional residual correlation matrices and computes Pesaran's (2004, 2015) normal-distributed CD statistic for strong/weak factor dependence.

### 5.1.10.1.2. Scope of Application and Sample Structure Requirements

Regional, trade, or financial panels exposed to common macroeconomic shocks or spatial spillovers across N cross-sectional units.

- **Mandatory Pre-Estimation Diagnostics**: `hausman_fe_vs_re, vif_multicollinearity`
- **Mandatory Post-Estimation Diagnostics**: `pesaran_2004_cd_test, wooldridge_panel_autocorrelation`

### 5.1.10.1.3. Structural Equations and Asymptotic Covariance Specification

Core structural equation for `pesaran_cd_cross_section_dep`:

$$
Y_{it} = \alpha_i + \lambda_t + X_{it}^\top \beta + \gamma^\top \bar{F}_t + \varepsilon_{it}, \quad i=1,\dots,N,\; t=1,\dots,T
$$

Estimator objective function and sample moment conditions:

$$
\mathbb{E}\left[Z_{i}^\top \Delta \varepsilon_i\right] = 0, \quad \hat{\beta}_{\text{GMM}} = \arg\min_{\beta} \left(\frac{1}{N}\sum_{i=1}^N Z_i^\top \Delta \varepsilon_i(\beta)\right)^\top W_N \left(\frac{1}{N}\sum_{i=1}^N Z_i^\top \Delta \varepsilon_i(\beta)\right)
$$

Asymptotic covariance matrix and robust inference metric:

$$
\widehat{\text{Var}}_{\text{CR}}(\hat{\beta}) = (X^\top M X)^{-1} \left(\sum_{i=1}^N X_i^\top M_i \hat{u}_i \hat{u}_i^\top M_i X_i\right) (X^\top M X)^{-1}
$$

# Runtime: Python 3.11+ | Estimator Key: pesaran_cd_cross_section_dep

df = pd.read_csv("vietlod_pesaran_cd_cross_section_dep_ecodata.csv")

# ECODATA replication & postestimation script - Pesaran Cross Sectional Dependence Panel Estimator (statsmodels::PesaranCrossSectionalDependencePanel)
# Family: panel_data / static | Key: pesaran_cd_cross_section_dep
import pandas as pd
# df: a pandas DataFrame holding your selected variables
import numpy as np, pandas as pd, statsmodels.api as sm
dy = df["y"] - df.groupby("entity")["y"].transform("mean")
dX = df[['x1', 'x2']] - df.groupby("entity")[['x1', 'x2']].transform("mean")
u = sm.OLS(dy, dX).fit().resid
piv = df.assign(_u=u).pivot_table(index="year", columns="entity", values="_u")
C = piv.corr().values; N = C.shape[0]; T = len(piv)
cd = np.sqrt(2 * T / max(N * (N - 1), 1)) * np.sum(np.triu(C, k=1))
print("Pesaran CD statistic:", cd)
