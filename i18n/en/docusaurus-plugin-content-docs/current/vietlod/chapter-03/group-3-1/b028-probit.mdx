## 3.1.2.1. Methodological Meaning and Scope of Application

### 3.1.2.1.1. Econometric Foundation and Identification Mechanism

Estimates the Binary Probit Regression specification within the Binary Choice Models framework by optimizing the structural objective function and computing heteroskedasticity- and cluster-robust asymptotic standard errors. Across empirical econometrics, `probit` enables researchers to isolate structural parameters while controlling for confounding covariates and verifying identification assumptions via `base Stata` in Stata 18 MP, `stats + margins` in R 4.x, and `statsmodels` in Python 3.11+.

### 3.1.2.1.2. Scope of Application and Sample Structure Requirements

Cross-sectional, pooled, or tabular microeconometric datasets requiring robust covariance estimation and specification testing. Mandatory post-estimation verification includes testing identification restrictions, evaluating goodness-of-fit metrics, and confirming numerical convergence across all three econometric engines.

### 3.1.2.1.3. Structural Equations and Asymptotic Covariance Specification

Core structural equation for `probit`:

$$
P(Y_i = 1 \mid X_i) = \Phi(X_i^\top \beta) = \int_{-\infty}^{X_i^\top \beta} \frac{1}{\sqrt{2\pi}}e^{-z^2/2}\,dz
$$

Estimator objective function and sample moment conditions:

$$
\hat{\theta}_{\text{MLE}} = \arg\max_{\theta \in \Theta} \sum_{i=1}^N \sum_{j=1}^J y_{ij}\ln P_{ij}(X_i; \theta), \quad \frac{\partial \ell_N(\hat{\theta})}{\partial \theta} = \sum_{i=1}^N s_i(Y_i, X_i; \hat{\theta}) = 0
$$

Asymptotic covariance matrix and post-estimation diagnostic metric:

$$
\text{AME}_k = \frac{1}{N}\sum_{i=1}^N \frac{\partial \text{P}(Y_i = 1 \mid X_i; \hat{\theta})}{\partial X_{ik}}, \quad \text{LR} = 2\left(\ell_N(\hat{\theta}) - \ell_N(\tilde{\theta}_0)\right) \xrightarrow{d} \chi^2_{\text{df}}
$$

# ==============================================================================
# MODEL 3.1.2 — CODE B028: BINARY PROBIT REGRESSION
# Runtime: R 4.x | Primary Package: stats + margins
# Practice Dataset: vietlod_probit_ecodata.csv | Sample Size N = 320
# Source URL: https://vietlod.tnsai.vn/src/ecoaz/data/vietlod_probit_ecodata.csv

  library(stats)
  library(sandwich)
  library(lmtest)
})

# 1. Load standardized empirical dataset
df <- read.csv("vietlod_probit_ecodata.csv", stringsAsFactors = FALSE)
summary(df[, c("y", "x1", "x2")])

# 2. Estimate model and compute HC1 robust covariance matrix
fit_probit <- lm(y ~ x1 + x2, data = df)
coeftest(fit_probit, vcov = vcovHC(fit_probit, type = "HC1"))
# Specialized stats + margins syntax: glm[y_bin ~ x1 + x2, family = binomial[link = 'probit'], data = df]

# 3. Run mandatory post-estimation diagnostics and report convergence
