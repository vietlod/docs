# Overview of the VietLOD Applied Econometrics Academic Portal

<Available plans={['EcoData', 'EcoLab', 'Finco', 'VietLOD']} />

**VietLOD** at [vietlod.tnsai.vn](https://vietlod.tnsai.vn/sach/kinh-te-luong-ung-dung-toan-dien-tu-a-z) is the flagship quantitative methodology portal and applied econometrics curriculum within the [TNS AI](https://www.tnsai.vn) ecosystem, encompassing **15 Chapters**, **58 Methodological Groups**, and **201 Econometric Models** spanning from foundation level `L1` to frontier research level `L4`. Every model features tri-engine execution scripts across **Stata 18 MP**, **R 4.x**, and **Python 3.11+**, standardized practice datasets, and three-software empirical convergence charts formatted to Q1 and Scopus journal standards.

## Four-Step Workflow for Using the VietLOD How-To Guides

<Steps>

### Step 1. Identify the Research Question and Data Structure

Browse the **15 Chapters** below based on the nature of your dependent variable and sample structure such as cross-sectional microdata, longitudinal $N \times T$ panels, macroeconomic time series, or spatial networks to select the appropriate methodological group.

### Step 2. Download the Practice Dataset or Synthesize Data via EcoData and Finco

Every model guide includes a standardized `.csv` dataset hosted at `/src/ecoaz/data/vietlod_<model_key>_ecodata.csv`. Researchers can also build custom empirical panels from [EcoData](https://ecodata.io.vn) and [Finco](https://www.finco.vn) following the Data Synthesis section in each guide.

### Step 3. Execute Code Across Stata 18 MP, R 4.x, or Python 3.11+

Copy the ready-to-run scripts from the interactive **Stata 18 MP**, **R 4.x**, and **Python 3.11+** tabs to estimate structural parameters, compute robust standard errors, and execute mandatory post-estimation diagnostics.

### Step 4. Verify Three-Software Convergence and Interpret Journal-Grade Output

Compare your estimated slope $\hat{\beta}$, standard error, $95\%$ confidence interval, and diagnostic $p$-value against the benchmark table and three-panel convergence figure, or run the model directly on [EcoLab](https://ecolab.io.vn).

</Steps>
