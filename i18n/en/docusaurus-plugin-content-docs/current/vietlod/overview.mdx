# Overview of the VietLOD Applied Econometrics Academic Portal

<Available plans={['EcoData', 'EcoLab', 'Finco', 'VietLOD']} />

**VietLOD** at [vietlod.tnsai.vn](https://vietlod.tnsai.vn/sach/kinh-te-luong-ung-dung-toan-dien-tu-a-z) is the flagship quantitative methodology portal and applied econometrics curriculum within the [TNS AI](https://www.tnsai.vn) ecosystem, encompassing **15 Chapters**, **58 Methodological Groups**, and **201 Econometric Models** spanning from foundation level `L1` to frontier research level `L4`. Every model features tri-engine execution scripts across **Stata 18 MP**, **R 4.x**, and **Python 3.11+**, standardized practice datasets, and three-software empirical convergence charts formatted to Q1 and Scopus journal standards.

## Four-Step Workflow for Using the VietLOD How-To Guides

<Steps>
  <div className="step-item">
    <h3>Step 1. Identify the Research Question and Hierarchical A.B.C Model Section</h3>
    <p>Browse the <strong>15 Chapters</strong> from <code>1</code> to <code>15</code>, <strong>58 Methodological Parts</strong> from <code>1.1</code> to <code>15.2</code>, and <strong>201 Model Lessons</strong> from <code>1.1.1</code> to <code>15.2.3</code> based on the nature of your dependent variable and sample structure.</p>
  </div>
  <div className="step-item">
    <h3>Step 2. Download the Practice Dataset or Synthesize Data via EcoData and Finco</h3>
    <p>Every model guide includes a standardized <code>.csv</code> dataset hosted at <code>/src/ecoaz/data/vietlod_&lt;model_key&gt;_ecodata.csv</code>. Researchers can also build custom empirical panels from <a href="https://ecodata.io.vn" target="_blank" rel="noopener">EcoData</a> and <a href="https://www.finco.vn" target="_blank" rel="noopener">Finco</a> following the Data Synthesis section in each guide.</p>
  </div>
  <div className="step-item">
    <h3>Step 3. Execute Code Across Stata 18 MP, R 4.x, or Python 3.11+</h3>
    <p>Copy the ready-to-run scripts from the interactive <strong>Stata 18 MP</strong>, <strong>R 4.x</strong>, and <strong>Python 3.11+</strong> tabs to estimate structural parameters, compute robust standard errors, and execute mandatory post-estimation diagnostics.</p>
  </div>
  <div className="step-item">
    <h3>Step 4. Verify Three-Software Convergence and Interpret Journal-Grade Output</h3>
    <p>Compare your estimated slope $\hat{\beta}$, standard error, $95\%$ confidence interval, and diagnostic $p$-value against the benchmark table and three-panel convergence figure, or run the model directly on <a href="https://ecolab.io.vn" target="_blank" rel="noopener">EcoLab</a>.</p>
  </div>
</Steps>
