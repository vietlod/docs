- **Methodological Focus**: Provides consistent estimation and robust inference for **Multivariate Volatility and Dynamic Correlation** specifications within **Financial Volatility, Asset Pricing and Systemic Risk**.

Core structural specification for Group 8.3:

$$
H_t = D_t R D_t, \quad D_t = \text{diag}(\sigma_{1,t}, \dots, \sigma_{K,t}), \quad R = [\rho_{ij}]_{K\times K}, \quad \sigma_{k,t}^2 = \omega_k + \alpha_k \varepsilon_{k,t-1}^2 + \beta_k \sigma_{k,t-1}^2

$$
\ell_T(\theta) = -\frac{1}{2}\sum_{t=1}^T \left[\ln(2\pi) + \ln(\sigma_t^2(\theta)) + \frac{\varepsilon_t^2}{\sigma_t^2(\theta)}\right], \quad z_t = \frac{\varepsilon_t}{\sigma_t} \sim \text{i.i.d. }(0, 1)
$$
