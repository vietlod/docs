## 2.3.1.1. Methodological Meaning and Scope of Application

### 2.3.1.1.1. Econometric Foundation and Identification Mechanism

Estimates the Principal Component Regression — PCR specification within the Dimension Reduction and Latent Factors framework by optimizing the structural objective function and computing heteroskedasticity- and cluster-robust asymptotic standard errors. Across empirical econometrics, `pcr` enables researchers to isolate structural parameters while controlling for confounding covariates and verifying identification assumptions via `base Stata` in Stata 18 MP, `stats / pls` in R 4.x, and `scikit-learn` in Python 3.11+.

### 2.3.1.1.2. Scope of Application and Sample Structure Requirements

Cross-sectional, pooled, or tabular microeconometric datasets requiring robust covariance estimation and specification testing. Mandatory post-estimation verification includes testing identification restrictions, evaluating goodness-of-fit metrics, and confirming numerical convergence across all three econometric engines.

### 2.3.1.1.3. Structural Equations and Asymptotic Covariance Specification

Core structural equation for `pcr`:

$$
Z_m = X V_m, \quad \hat{\beta}_{\text{PCR}} = V_m (Z_m^\top Z_m)^{-1} Z_m^\top Y
$$

Estimator objective function and sample moment conditions:

$$
\hat{\beta}(\lambda, \alpha) = \arg\min_{\beta \in \mathbb{R}^p} \left\{\frac{1}{2N}\sum_{i=1}^N \left(Y_i - X_i^\top \beta\right)^2 + \lambda\left(\alpha \|\beta\|_1 + \frac{1-\alpha}{2}\|\beta\|_2^2\right)\right\}
$$

Asymptotic covariance matrix and post-estimation diagnostic metric:

$$
\text{CV}_K(\lambda) = \frac{1}{K}\sum_{k=1}^K \frac{1}{|I_k|}\sum_{i \in I_k}\left(Y_i - X_i^\top \hat{\beta}^{(-k)}(\lambda)\right)^2, \quad \lambda_{\text{opt}} = \arg\min_{\lambda}\text{CV}_K(\lambda)
$$

  library(stats)
  library(sandwich)

# 2. Estimate model and compute HC1 robust covariance matrix
fit_pcr <- lm(y ~ x1 + x2, data = df)
coeftest(fit_pcr, vcov = vcovHC(fit_pcr, type = "HC1"))
